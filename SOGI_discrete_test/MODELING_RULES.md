# Simulink 参数化建模规范

本规范适用于后续新建算法模型，SOGI 用作说明示例。**FE 三个真实物理参数端口、直接差分结构及功能命名已实施，结构/编译接口检查为 213 PASS、0 FAIL；实际 FE 输入校验与数值仿真均为 NOT_RUN。** 检查记录见 [FE 修改记录](reports/fe_physical_inputs/change_record.md)。 不以现有面板、脚本或历史报告宣称新接口通过。BE/Tustin/ZOH 仍是字典型方案，正式参数输入待独立改造；其它旧模型不迁移、不重排、不重命名。

“必须”表示交付门禁；“建议”表示可按算法理由调整并记录。通用模型按算法选择适用离散方法、参数接口及验收指标，不强制比较四种方法，也不强制采用 SOGI 字段或函数名。下述数值与复用验收仍是后续流程；本轮只落实已授权的 FE 结构范围并同步规范。

## 1. 来源与 MATLAB 脚本前置门禁

必须按 **资料方程 → 参数化 MATLAB 离散化脚本 → 脚本快速仿真通过 → 信号定义与模型接口合同 → Simulink 建模 → 后续验证门禁** 顺序推进。不能用一份静态系数表代替参数化推导。通常通过脚本门禁后才建模；本次用户明确授权先修改 FE 接口结构、暂不运行新数值验证，须记录该执行例外，不能据此把 preflight 标为 PASS。

1. 记录资料版本、页码/公式号、输入输出、物理参数、单位、状态定义、有效范围、初值、复位、输入保持假设及输出计算时刻。资料提供传递函数或状态方程其中一种即可；两者都有时必须交叉核对。由一种推导另一种时注明“推导参考”，不得称为第二份独立来源。
2. MATLAB 脚本必须显式接受物理参数、采样周期和所选方法，并据此重建方程、离散系数及响应。基础参数与派生系数分开，修改参数后可重新计算。允许使用数学常数 0、1 等；不得把应可配置的参数或离散系数硬编码。
3. 记录每种候选方法的适用性与选择理由。例如线性采样保持对象可比较 ZOH，频率特性重要时可比较 Tustin，显式状态更新可比较前向欧拉；后向欧拉或非线性积分方法须说明隐式求解和代价。不能强迫非线性状态方程使用不适用的线性离散方法。
4. 快速仿真应只依赖脚本的显式输入，不加载 SLX/SLDD，不使用隐藏基础工作区参数。先检查参数和稳定性，再比较适用的时域响应、频响及采样周期敏感性。线性系统检查离散极点；非线性系统采用相应有限性、界限及轨迹指标。记录数据类型、初值、输入保持、更新顺序和预先确定的量化容差。
5. 实际执行并满足已规定指标才记 PASS；失败记 FAIL，未执行记 NOT_RUN。探索中失稳的方法必须记录参数、判据和跳过原因，跳过回放不能算通过，也不能用限幅隐藏发散。用于建模的选定基准必须满足其稳定性要求并通过脚本门禁；方程、方法或基准改变后重跑。

SOGI 的拟定试例是 f0=50 Hz、Ts=50e-6 s、k=sqrt(2)，比较 FE/BE/Tustin/ZOH；如果四方法同时作为建模基准，则四者都必须稳定。FE 失稳探索可标记并跳过，但不能放行该四方法基准。`run_sogi_preflight(f0,Ts,k)` 是试验中的参考入口名称，Ts 以秒计；不把其名称、文件存在或本次文档修订视为已验证依赖或实际 PASS。后续应归档响应、极点/稳定性、频响、误差及失败/跳过记录。

## 2. 正式接口与参数化合同

**参数化必须落实为模型输入。** 参数可使用独立输入端口或类型化总线，按算法规模和复用要求选择；只有 SLDD、全局变量或蓝色配置面板不构成参数输入接口。接口合同必须列出信号、复位、参数、输出的名称、顺序、类型、维度、单位、合法范围和时序。

- 核心算法的参数数值只能来自明确的输入端口。不得通过 `evalin`、`slResolve`、直接字典查询或其它全局解析取得运行参数，也不得把 Gain 的系数直接绑定为外部字典数值。可直接使用物理参数展开选定差分方程，或解包外部派生系数后与状态/输入作乘加；0、1、2π 等数学常数可放在 Constant/Gain 中。
- 每种方法记录采用“物理参数直接展开差分”还是“外部离线系数快照”。MATLAB 离线推导和参考必须保留，但不强制所有方法以 Ad/Bd/Cd/Dd 作为输入。采用派生系数输入时，系数须统一生成、只读且不单独手调。配置源/包装层在运行前校验实际输入的类型、有限性、单位、范围、稳定性和采样周期；若提供派生系数，还须检查其与物理参数一致。不得只检查字典值就认定模型输入正确。
- 参数快照在仿真前提供，并在该次运行中保持不变。修改物理参数应停止后重新派生和校验；复位只重置实例状态，不触发参数重算或字典写入。在线调参若另有要求，必须单独设计，不能隐含加入本规范。
- 实例必须分别拥有状态、复位及参数输入。不得通过共享可写全局状态使两个实例互相影响；同一模型可以由两个外部合法快照驱动，而不要求先改一份全局字典再轮流运行。
- 核心算法建议继承实例采样周期，或由外部包装层显式配置。参数中的 Ts 是快照的设计周期，必须与编译后的实例调度一致；它不是运行中的调度控制端口。改变 Ts 必须停止、重新离散化并重新编译，不能承诺运行中改 Ts 会改变采样率。
- SLDD 可以保存类型定义和外部基准配置。SOGI 基准仍以 `sogi_parameters.sldd` 为唯一保存来源，避免重复同名数值和基础工作区依赖；独立复用可直接接收外部合法快照。类型定义依赖与参数数值依赖必须区分。

### 信号定义与对象规则（建模前合同）

先定义再接线。信号分为外部输入、输出、中间量、状态、控制/复位、物理参数信号和派生系数。正式接口、共享、状态及记录信号必须有明确定义；纯局部连线允许通过差分方程和块名映射说明，不要求每根线都建对象。

每个受管理信号必须记录：

| 定义项 | 必填内容 |
|---|---|
| 身份与含义 | 类别、实际物理或数学含义、实例角色、完整名称/简图名映射 |
| 量纲与表示 | 单位、参考正方向/坐标系、PU 基准、数据类型、维度和范围；不适用项明确注明 |
| 时序与来源 | 采样周期/速率、当前拍/下一拍与延迟、唯一生产者和所有消费者 |
| 状态与异常 | 初值、复位优先级、有效条件及 valid/失效/NaN 处理政策；由算法合同决定 |
| 使用与绑定 | 是否记录/XCP 暴露、代码接口角色、信号对象位置、实际线名/对象名和绑定方式 |

范围元数据不等于限幅、断言或运行保护；不得为了满足定义自行添加饱和、替代值或 valid 端口。异常处理按算法合同实施并单独验证，未定义时先补合同。SOGI 的 1 PU 是本试例输入幅值，不是通用量程；u、D/Q 和状态范围按工况确定，不能机械限定为 [-1,1]，未确定填写“待定”且不宣称该门禁 PASS。

需要统一类型、单位、范围、记录或代码接口的信号，必须在试例独立 SLDD 中定义 `Simulink.Signal`，明确实际线名与对象同名映射并显式绑定/解析。对象存在不代表已经绑定；须核对实际解析对象及编译传播结果。并非合同的全部属性都存在于 Signal 对象：采样时序等应在端口/块配置中定义并记录到合同。Min/Max 可参与初值检查或启用范围诊断后的报警，不会自动限幅；默认关闭范围诊断时不能宣称运行值已受范围约束，见 [信号属性与显式解析](https://www.mathworks.com/help/simulink/ug/sim-signal-property-dialog-box.html) 和 [Simulink.Signal](https://www.mathworks.com/help/simulink/slref/simulink.signal.html)。核心仍通过端口取数值，字典类型/元数据不能变成隐藏的参数数值来源。同一作用域每个命名信号只有一个生产者；多个实例的状态及实参隔离，不能因同名全局对象而共享状态。

必须区分 `Simulink.Parameter`（外部标定值）与 `Simulink.Signal`（信号属性）。分别记录端口显示名、实际线名、对象名和对象类别；显式解析的实际线名必须匹配 Signal 对象名。若 Cal 名称已被 Parameter 占用，不得覆盖为 Signal 或强制端口解析到错误对象类型；另取唯一信号对象/线名，保留原 Cal 端口和 XCP 标识。本规则不要求本轮创建或迁移对象。

SOGI 示例：`Input_PU/u` 是 PU 输入，`Reset_States` 为 uint8、非零有效；`Cal_SOGI_F0_Hz_f32`、`Cal_SOGI_K_f32`、`Cal_SOGI_Ts_s_f32` 虽以 Cal 命名，仍是进入 FE 的物理参数信号。`InPhase_D_PU/D` 与 `Quadrature_Q_PU/Q` 为当前拍物理输出，`Dnext/Qnext` 为下一拍状态候选；Q 更新使用当前 D。D/Q 既有 XCP 名称保持，完整名称与简图名逐项映射。SOGI 的 PU 输入输出使用同一基准；实际物理基准值/参考方向由复用实例记录，不能仅写“PU”。

FE 的 Dnext/Qnext 由复位选择后的当前输入/状态计算并写入 Unit Delay，复位有效且参数有限时为零；零初值属于延时保存状态，不要求任意首拍候选为零。连续标准 SOGI 的中心频率正交相位定义不等于 FE 离散相位已验证。

本轮只补信号规则，不要求改动模型或实际对象；新增定义/绑定/传播/异常策略验收未执行项目记 NOT_RUN，不据既有结构检查宣称已满足。

### SOGI FE 本轮授权接口（结构已实施，数值未运行）

结构/编译检查为 213 PASS、0 FAIL，记录见 [FE 修改记录](reports/fe_physical_inputs/change_record.md)；实际 FE 输入校验为 NOT_RUN，不以结构通过代替运行保护。FE 方法子系统名称为 `SOGI_DualOutput_Filter_FE`，采用五个正式输入和两个输出：

| 顺序 | 输入 | 类型与单位 |
|---|---|---|
| 1 | `Input_PU` | single 标量，PU |
| 2 | `Reset_States` | uint8 标量，非零复位 |
| 3 | `Cal_SOGI_F0_Hz_f32` | single 标量，Hz |
| 4 | `Cal_SOGI_K_f32` | single 标量，无量纲 |
| 5 | `Cal_SOGI_Ts_s_f32` | single 标量，s |

输出为 `InPhase_D_PU`、`Quadrature_Q_PU`，均为 single 标量 PU。状态就是物理 D/Q，直接展开：

```text
Dnext = D + Ts * 2*pi * f0 * (k * (u - D) - Q)
Qnext = Q + Ts * 2*pi * f0 * D
```

核心使用 single 的 Product、Sum、常数 2π Gain 和 Unit Delay 等基础模块。三个参数端口必须真实连接并参与上述运算，不得是假端口，也不得查询字典系数。先输出当前状态，再计算并保存下一状态；复位优先，复位期间输出与保存的下一状态均为零。

比较模型新增三个外部物理参数输入驱动 FE；验证模型在核心外使用字典 Constant 接入这三个端口。核心 Unit Delay 继承外部实例采样周期；Ts 是参与差分运算的真实数值输入，必须等于实例编译调度，不控制调度。f0/k/Ts 在仿真前提供、运行期间冻结。FE 外部实际输入一致性校验尚待实施/验收，当前结构修改不能证明运行输入已有保护。

BE/Tustin/ZOH 本轮仍保留字典型系数方案，不声明已完成参数端口改造。原拟议 51 字段 Params 总线及 `sogi_parameter_bus`/`sogi_parameter_bus_type` 草稿本轮不采用，仍未验收；它不是所有方法的强制方案。

蓝色 `SOGI PARAMETERS` 面板只是外部配置辅助，应显示完整符号、物理含义、单位及字典实际值，区分未保存状态；Ts 面板单位 us，存储和脚本单位 s。面板不得代替真实参数端口，也不得把测试输入显示为字典值。已有 getter/setter/refresh 仍需按实际接口复核；setter 应拒绝运行中、Fast Restart 开启或已有未保存更改时写入。

### 输入检查与运行门禁

后续正式输入验收要求外部配置/包装层必须只读校验实际传入的完整参数快照，并在首个算法步之前拒绝非法、失配或周期不一致的配置。编译后若需要判断扫描候选是否真正停用，应检查有效编译活动状态；保存的 Commented 值不能证明临时覆盖生效。`CompiledIsActive` 的意义见 [MathWorks 块参数与属性说明](https://www.mathworks.com/help/simulink/slref/block-parameters-and-properties.html)。活动失稳方法不得运行，非活动探索项应明确标记。

现有按全局名称解析的 InitFcn/StartFcn 只是字典型试验实现，不是可复用参数接口。FE 的实际输入校验策略尚待实施/验收，不能声称已有运行保护；本规范不锁定回调名、布尔实参或具体函数调用。核心不查全局参数，任何检查或复位均不得回写参数、模型或字典。`Simulink.data.resolveInGlobal` 是外部模型上下文解析 API（[R2024b+ 官方说明](https://www.mathworks.com/help/simulink/slref/simulink.data.resolveinglobal.html)），不能代替 FE 物理参数端口或未来总线的输入校验。

## 3. 功能命名规则

最终名称必须使读者结合接口即可判断功能与角色，无需打开核心内部。名称和紧邻注释共同完整，不强制每个基本块使用冗长名称；但不得以默认编号或孤立矩阵下标作为最终名称。

| 对象 | 必须表达的内容 | SOGI 建议示例 |
|---|---|---|
| .slx 文件 | `<algorithm>_<function>_<role>.slx`；角色可为 discrete、validation、wrapper | `sogi_dual_output_filter_discrete.slx`、`sogi_dual_output_filter_validation.slx` |
| 方法子系统 | 算法、功能、实际离散方法 | `SOGI_DualOutput_Filter_FE`、`SOGI_Filter_Tustin` |
| 基本块 | 运算或状态角色，必要时补信号/用途 | `Weight_State1_For_D`、`Sum_D_Output`、`Update_State1`、`Delay_State1` |
| 复用实例 | 实际应用角色，不能仅编号 | `SOGI_Voltage_Alpha`、`SOGI_Current_Beta` |

- 同一作用域名称必须唯一；Gain1、Sum1、Subsystem2 等自动编号名、A11 等孤立下标不得作为最终交付名称。单位、离散方法及角色按辨识需要加入，不重复堆砌。
- 可复用模型名称不得固化可配置的频率、增益或采样周期数值；这些值写入实例配置及试验记录。参数改变后功能名应仍然准确。
- A11、Bd 等数学符号保留在参数名称和紧邻公式映射注释中，不与功能名称混为一谈。FE/ZOH 物理状态与 Tustin 等辅助状态要明确区分，名称或注释说明实际含义及当前拍/下一拍。
- XCP 完整参数/信号名称保持现有规则，不为新块名迁移现有符号。长功能名应扩大空间或合理分层，不能缩小 14 pt 字体来容纳。
- 本轮授权 FE 子系统采用上述功能名，并按直接差分运算角色命名内部块、更新相关依赖；模型文件及其它方法的全面改名属于后续实施和验收。

## 4. 图面、布线与可读性

本次紧凑调整仅涉及 FE 内部坐标、尺寸、注释与布线，保留方程、接口、拓扑和 Arial 14 pt；其它方法内部及外层接口不改，不运行数值仿真。实测尺寸、缩减和审阅结论见 [紧凑布局记录](reports/fe_compact_layout/layout_review.md)；后续案例同样须实际量测，不预填结果。

1. 常规信号按“输入 → 预处理 → 算法计算 → 后处理/误差 → 输出”固定列序向右流动；可省略不需要的阶段，不能倒置。并行支路上下分行；信号、reset/控制、参数配置输入分行并标注作用。同功能、同端口签名及显示形式的模块组统一尺寸；端口数不同时允许分组定尺，通过列序、基线和行距协调全局，不能强制所有分支同高。每个分支的完整名称仍须分别复核。
2. 连线必须为水平/垂直折线，斜线数和穿过无关模块内部的线段数必须为零。不得遮挡块名、参数文字、信号标签或注释；必须另行检查不同信号线相交、共线重叠及 T 形假连接，不能只检查线与模块的碰撞；复位、零值等不同信号使用分离通道。无连接交叉和不同信号重叠应消除。零长度段不是有效连接，不能屏蔽问题线获得通过。
3. 长线或多扇出可使用同层 local Goto/From，每个标签只有一个可追踪生产者；禁止 global/scoped 标签隐藏跨层依赖。普通消费者仍须位于生产区右方，不能用标签或无意义折返掩盖链路倒置。
4. 状态更新和反馈置于下方独立区域并标明含义；复位首拍对外发布的有效状态及输出必须按合同清零。连续状态读出用于普通输出打包属于前向后处理，放在生产区右方，不能冒充内部反馈。
5. 新模型默认 Arial 14 pt，禁止小于 12 pt；SOGI 目标统一 Arial 14 pt。长方形运算模块（含系数乘法、Gain、转换）宽至少 120 px；Sum 等标准符号宽至少 40 px；Unit Delay 宽至少 70 px。SOGI 方法子系统历史 300×165 px 下限按本节 10 px 网格向上取整为 300×170 px，实际尺寸还须满足端口及文字计算。采样接口不属于运算模块，SOGI 原验证 SampleHold 宽 110 px。
6. Model Reference 宽度应覆盖完整左右端口标签并留出中央空白。原 SOGI Four_Methods 的 620×480 px 仅作旧接口布局参考；加入三个物理参数端口后按完整新接口重新检查。Inport/Outport 保留标准形状，名称空间须单独验收，标签不能截断。
7. 新层级模块默认关闭内部预览，进入子系统阅读方程；使用 `ContentPreviewEnabled='off'` 避免内容缩略图覆盖端口名称。[MathWorks 内容预览说明](https://www.mathworks.com/help/simulink/ug/preview-content-of-hierarchical-items.html) 解释了该属性。
8. 编辑器默认 100% 缩放并允许滚动；适配窗口只用于导航，不能当成字号可读性验收，也不能以极大画布作为达标手段。编辑器视图和可读导出图分别检查，兼顾整体可扫读与局部全文清晰，名称变长按内容加宽，不缩字。
9. 矩形 120 px、Sum 40 px、Unit Delay 70 px 和本例 Arial 14 pt 是可读下限，不是全图成倍放大目标。先压缩过量空白与线长，模块按内容适配尺寸；每个方程按功能成行成组，相关操作就近，说明贴近对应区域。保持普通信号左到右，禁止蛇形折返伪装顺序。
10. 单个方程组尽量在常用审阅窗口完整追踪；压缩空白后仍过宽，才考虑带清楚接口的功能层次，不默认要求本轮改变拓扑。记录修改前后绘图区包围尺寸（含块、线和注释）、宽高缩减及同一审阅缩放下的截图，同时检查整体可扫读和局部清晰。几何 PASS 不能替代人工审阅便捷性。

SOGI 原布局模板记录：输出两行在上、状态更新两行在下；四方程区整体右移后 From/Gain/Sum/Unit Delay 列约为 x=990/1268/1538/1710，行距至少 240 px、同式三项间距 66 px，预处理区留在左方。它不是通用模型固定坐标；本次新坐标同样只是具体布局选择，不构成通用目标，也不能仅据坐标声明新接口满足布局规范。

加法、乘法等满足交换律时，应按来源在图面上的上下顺序选择输入端口，避免上方参数跨越主信号；交换后核对符号与操作数映射。减法、除法及矩阵运算顺序不得为了美观交换，不能改变方程语义。

后续结构编辑使用 model_edit，随后 model_read/model_check。布局脚本只能在其支持的已核对结构上应用，不能假定旧名字在重命名后仍有效。移动模块后须按实际端口重新布线并检查缺线、残留分支点和遮挡；结构检查不证明语义正确。

### 4.1 定尺输入、单位与项目基准

**先按接口和内容计算单块，再统一可比组，最后安排整层。** 以下数值是本项目的布局起始值，不是 MathWorks 固定标准；公式给出初算尺寸，最终以实际端口间距、文字净空和全局审阅验收为准。用户随后授权按本规则调整：两个 SOGI 模型的七个图层已实施端口感知定尺，实际范围和检查见 [本轮布局记录](reports/port_aware_layout/layout_review.md)。本轮不运行编译或数值仿真，不以布局验收替代算法验收。

规则强度：既定字号、分类尺寸下限、文字净距 10 px 和相应类型端口最低节距 20/40 px 是项目验收要求，不能因“非软件硬限制”而忽略；公式、边距、60/100 px 列间空隙及布线通道取值是设计起点，允许按实际占位修正并记录。10 px 网格用于块体尺寸和位置安排，实际端口可能不在该网格上，线端必须连接真实端口坐标，不能移动或伪造端口来凑网格。特殊块型若需偏离通用下限，应记录适用范围和等效可读判据，单独审阅，不按通用项自动 PASS。

每个块先登记：块类型/功能、方向、四边实际可见端口数 `nL/nR/nT/nB`、各端口完整显示标签及其文字宽高、内部符号/数值/标题、外部块名、注释、所属可比组。必须区分端口类别与端口名称：作为普通 Inport 接入的 reset 计入所在侧；真正顶部 Enable/Trigger/Reset 控制口另计顶部，不能只看名称判断。

- 一个向量或总线的可见连接口计 **1 个端口**，不按元素数增加高度。元素展开为多个可见连接口后重新统计；不为压缩尺寸擅自把用户要求展开的 f0/k/Ts 合并成总线。
- 统计实际配置的端口，包括参数和控制口；端口数可变、变体或显示方式变化时重新统计，不沿用旧图的数量。无端口或单端口必须有明确分支，不能算出负间距。
- 本节 px 指模型坐标单位。字体使用 pt，**14 pt 不等于 14 px**。文字尺寸按同字体、字号、显示设置实测；截图或导出图测量需换算到模型坐标，不能把高分辨率导出像素直接用作块坐标。字符数估算只可起草，不能替代最终量测。

| 项目 | 起始值/规则 |
| --- | --- |
| 网格 `g` | 10 px；`ceil_g(x)=g*ceil(x/g)`，计算尺寸向上取整 |
| 短符号基本块的同侧端口节距 `p0` | 20 px |
| 显示完整命名端口的层级块节距 `p0` | 40 px |
| 相邻文字最小净距 `dText` | 10 px；多行标签按真实高度增加节距 |
| 块内边距 | 基本块起始 10 px；层级块起始 20 px，另容纳实际标题/符号 |
| 层级块左右标签之间的中央区域 `C` | 起始 80 px；有内部标题/图标时按其实际宽度增加 |
| 直行列间空隙 `G0` | 基本运算区 60 px；层级接口区 100 px；长信号标签和转弯通道另计 |
| 独立平行转弯通道间距 `t` | 20 px；不表示直连的每个端口都要增加一列通道 |
| 方程组/并列分支外部占位框间距 `V0` | 60 px；有反馈、控制或注释通道时按需要增加 |

### 4.3 单块宽高计算与实际端口修正

侧端口标签按端口中心对齐。对同侧相邻两个标签，文字高度为 `h_i`、`h_(i+1)`，要求中心节距至少为 `(h_i+h_(i+1))/2+dText`；同侧统一节距取该值与类别 `p0` 的最大值，并向网格上取整。无相邻端口时不计算相邻项。上下边距 `mt/mb` 还须容纳首末标签的半高、边界净空和实际内部标题。

等节距初算可写为：

```text
N = max(nL,nR)
p = max(左右两侧所需节距)             # 无侧口时使用类别起始值
Hport = 0                           # N=0
Hport = mt + mb + (N-1)*p            # N>=1
H = ceil_g(max(Hmin, Hport, Hinside))

Wlabels = 2*mx + L + C + R
W = ceil_g(max(Wmin, Wlabels, Wtop, Wbottom))
```

`Hinside` 为内部图标/标题/数值及其净空所需高度；`L/R` 仅为**显示在块体内部**的左/右端口标签最大宽度，无该类标签时取 0；`C` 容纳中央符号、文字或留白；`mx` 为左右内边距。普通运算块没有内部端口标签时按中央图标/表达式和其类别下限定宽。外部块名、外侧端口标签和邻近注释放入占位框，不重复计入左右内部标签宽度。

`Wtop/Wbottom` 按顶部/底部实际连接点、标签宽度及横向节距另算；无该侧端口时为 0。顶部控制口的图标、标签和入线区域也必须加入外部占位框，不能加到左输入数量里后就忽略顶侧冲突。一般四边接口按各侧真实布局处理，不为美观改变端口性质或运算顺序。

初算完成后必须读取每个实际端口的模型坐标，逐侧检查相邻间距、边缘净空及标签。**公式的 p 不是设置块高后就必然得到的真实节距。** 若存在小于要求的实际节距 `pActual>0`，可用下式扩大后再读取；只取所有不满足端口对中最严格的修正量：

```text
Hnew = ceil_g(max(H+g, H*pRequired/pActual))   # 左/右侧节距不足
```

顶部/底部横向节距不足时相应修正宽度；若 `pActual=0`、端口重合或配置变化，先检查实际端口和块型，不能除零或无限重复放大。宽度不足按真实文字溢出量增加；外部名字冲突优先扩大其占位/列距，不无条件把所有块体变宽。迭代至实际间距和全文显示满足要求，并记录初算与最终尺寸差异。

设置 Position 后还须回读块体本身：Simulink 可能按实际端口分布调整请求坐标，不能仅检查脚本中的尺寸是否落在网格上。选择满足接口、留白和最终网格的下一合适尺寸，再回读确认。线端验收使用真正连接位置：本次安装中 PortHandles 的输入 Position 与块的 PortConnectivity.Position 存在箭头显示偏移，线 Points 的末点由 Simulink 规范到后者。应记录两种坐标并检查源目标端口身份，不在通用规则中硬编码偏移或放宽端点容差。参见 [MathWorks 端口连接坐标示例](https://www.mathworks.com/help/simulink/slref/add_line.html)。

### 4.4 同类模块组与全局匹配

每层定义可比组 ID，分组依据为 **功能类别、可见四边端口签名、方向、标签显示形式**。相同组采用 `Wgroup=max(Wrequired)`、`Hgroup=max(Hrequired)`，并按同一网格取整；组内仍须逐个检查不同长名称。统一以满足组内需求的最小共同尺寸为目标。

- Gain/转换、Sum、Delay、层级接口分别成组；不能为了与一个八端口接口同高，把全部单输入运算块放大。
- 端口数量不同的同功能模块可分子组，保留共同列序、列基线和必要的共同宽度，高度按各自端口需求确定。若为对照选择共用宽度或行高，应记录理由，不能默认共用全图最大宽高。
- 个别超长内部标签先确认完整命名是否必要，再扩大其组或划分合理子组；外部名称过长主要影响占位框。禁止通过截断 XCP 名称、缩小字号、隐藏必需标签或无意义拆组规避尺寸要求。
- 同一方程按真实生产/消费关系和当前拍/下一拍定义排列对应操作；D/Q 等并列链对齐等价功能，复位置于算法规定的实际处理位置，状态反馈独立标明。不能把一套固定列名当成通用执行时序。对齐按选定主端口/中心基线进行，连接以实际端口为准，不能为全画面直线更换操作数、挪动复位逻辑或增加虚假延时。

### 4.5 外部占位、列宽、行高和布线通道

每块的占位框 `E` 至少包含：块体、完整外部块名、外侧端口标签、邻近功能说明、顶/底控制口图标及标签。文字与块体分别量测；作为线标签显示的文字预留在实际线段区域。按主端口或基线对齐后，列宽取该列占位框投影并集：`Cj=max(xmax(E))-min(xmin(E))`；行高取该方程/分支投影并集：`Rr=max(ymax(E))-min(ymin(E))`。不能只取单个块宽/高的最大值，忽略对齐偏移、顶侧控制或外侧文字。

以各占位框区域的左上界作为列行定位基准，满足：

```text
X(j+1) >= X(j) + Cj + Gj
Y(r+1) >= Y(r) + Rr + Vr
Gj = ceil_g(max(G0, 2*c + max(0,q-1)*t, WlineLabel + 2*c))
```

`c` 为通道侧净空，起始 20 px；`q` 为该间隙中**实际需要的独立转弯通道数**，直行并列连线不按总端口数盲目加宽；`WlineLabel` 为该间隙需完整放置的最长水平信号标签宽度，无标签时取 0。`Vr` 起始 60 px，有状态反馈/控制/注释通道时按真实需求增加。相邻通道、文字和块体均须满足净空，零值与复位等不同信号不能共用线段。

调整单块尺寸后，按“该块→可比组→所在列/行→相邻布线通道”传播布局变化，保留其它无关分组。避免一处长名引起全图等比例扩大；优先回收无用留白。单方程组仍无法在常用审阅窗口追踪时，先审查冗余列距与注释位置，再评估有明确功能和接口的层次划分，不能用蛇形折返或缩字适配窗口。

布线验收补充：不同网即使没有数学交点，平行段间距过小也会看成重叠或 T 形假连接。必须测量投影有正长度重叠的平行段间距；SOGI 本轮将所选通道间距 20 px 作为实际验收值，同源分支单独识别，不能靠 1 px 错开获得 PASS。命名线在首个转折之前预留完整实测标签宽度及至少 20 px 余量，或明确安排其它足够长的标签段；转折后的线也不得穿字。线标签没有真实位置数据时，自动项保留 NOT_RUN，并以最终导出图逐条人工记录补足，不能用块名包围框替代信号标签。

### 4.7 必须执行的定尺流程与记录

1. 冻结待建接口：登记实际各侧端口数、顺序、标签、方向、控制类型、字体与显示方式。
2. 量测内部/外部文字和符号，按类别与公式计算每块初始宽高、外部占位框，保留原始测量值。
3. 划分可比组并取组内最小共同尺寸；根据占位框计算列宽、行高与独立布线通道，不把最大多口模块尺寸传播给全部块。
4. 应用尺寸并回读实际端口坐标，修正节距、边缘净空和长标签；更新受影响分组/列行，再用实际端点作直角布线。
5. 读取结构并执行 model_check；分别检查块体、完整文字、线间交叉/重叠、顶侧控制、同组一致及实际端口间距。回读最终 Position 网格，使用实际连接坐标验收线端，并检查独立平行通道间距和命名线标签段。人工在 100% 和完整导出视图审查全局匹配及逐段追踪；导出前清除临时查找高亮，不改变功能色标；未测量项为 NOT_RUN，线标签人工证据单列。
6. 新增/删除端口、总线展开/收拢、名称或字号改变、方向/显示形式改变时，重新执行上述步骤。若改变功能接口/连接，另按结构及数值门禁执行；纯几何变更也必须重查布线和图面，不假借旧 PASS。

每块/组记录至少包含：`作用域与块名、类别、组ID、nL/nR/nT/nB、L/R与各标签高度、内部内容宽高、边距/节距/网格、初算W/H、组定W/H、最终W/H、实际最小端口间距、外部占位框、列/行与通道数、尺寸偏离原因、结构/人工状态及截图`。通过条件是实际测量满足该块需求并与所在组、列行协调；单纯“大小看起来一致”或“计算公式已运行”不能记为通过。

## 5. 后续实施与验收门禁

**本轮 FE 结构已实施，结构/编译接口检查为 213 PASS、0 FAIL，见 [FE 修改记录](reports/fe_physical_inputs/change_record.md)。实际 FE 输入校验、数值与复用验收均为 NOT_RUN。** 图面及线间关系按实际独立记录评价，不由结构检查代替。后续完整验收仍按以下顺序推进，不能以已有试验 PASS 替代新接口验收。

1. 来源/脚本门禁：完成资料合同、方法理由和参数化快速仿真；基准通过后才进入接口与模型实施。
2. 信号/接口门禁：先填写信号定义表，覆盖类别、含义、全名/简图名、单位/方向/坐标/PU 基准、类型/维度/范围、拍次、来源去向、初值/复位及异常/记录政策；再按定义接线和绑定。核对 reset、参数端口/总线、运行冻结及实例隔离。外部 Source 提供合法快照；核心没有全局数值查询或字典系数绑定。校验实际输入，不只查保存配置。
3. 命名/结构门禁：核对文件、子系统、基本块和实例名称；名称加接口应说明功能，名字加紧邻注释应能映射方程，禁止默认编号和孤立下标。按各作用域读取结构并检查连接；编译核对传播后的信号类型、维度、采样周期与定义一致，验证实际对象绑定而非只检查对象存在。未执行项记 NOT_RUN，元数据不等于取值约束。
4. 图面门禁：先执行 §4.1–4.7 的“端口/文字量测→单块初算→同组统一→列行/通道→实际端口回读→路由→审阅”定尺流程，再按功能压缩过量空白和线长，保持可读尺寸、字号与从左到右的顺序。逐个审查所有作用域，不以相同拓扑免除不同长标签的检查。核对字号、尺寸、完整参数名、功能命名、预览关闭、线段几何和文字留白；沿信号/参数输入到输出追踪真实语义顺序，辨认控制分发、前向处理与状态返回。同时逐线检查不同信号相交、共线重叠、T 形假连接、复位/零值通道分离及交换律允许的端口选择，核对减法/除法/矩阵操作数顺序。人工记录与自动检查分开，自动块避障 PASS 不能替代线间关系、图面和命名语义审查。另查整体可扫读、单方程组追踪及局部全文清晰，归档每块定尺记录、前后绘图区尺寸/缩减和同缩放截图；几何合格不等于便于人工审阅。
5. 数值门禁：模型与已通过脚本在相同输入、参数快照、初值和时序下逐拍比较，不移动时间轴掩盖一拍误差；包括复位、边界和非法输入/参数。容差在运行前定义，稳定性和算法特性按适用范围评价。
6. 复用门禁：至少用两个同时存在的实例、不同合法参数快照和独立复位，验证一个实例的参数/复位不会影响另一个状态或输出。仅改单实例参数再顺序运行不能证明复用。改变 Ts 后停止、重离散化、重编译，检查端口 Ts 与实例调度一致；运行冻结和不一致配置要有拒绝证据。
7. 归档门禁：保存脚本、方法选择、接口和命名记录、参数及类型版本、模型、测试输入/输出、原始误差及实际状态。静态检查、人工图面与数值报告分别记录；任何报告只证明其实际执行范围。
