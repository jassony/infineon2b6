# SOGI 四种离散化建模试例

本目录保留独立 SOGI 滤波器试验资产，用于完善参数化建模、功能命名、布局和验证流程规范。试验基准为 `f0 = 50 Hz`、`Ts = 50 μs`、`k = √2`、正弦输入幅值 `1 PU`、零初始状态。算法执行采用固定维度 `single`，数学参考采用 `double`。

本试例只涉及滤波器；除本轮授权的独立试例 FE 修改外，不修改其它旧模型，不接入 FOC、PLL/FLL，不生成或修改 A2L，不声称通过代码生成、IAR 构建或台架验证。

**FE 三个真实物理参数端口、直接差分结构及功能命名已实施；结构/编译接口检查为 213 PASS、0 FAIL。** 记录见 [FE 修改记录](reports/fe_physical_inputs/change_record.md)。实际 FE 输入校验、数值仿真和双实例复用为 NOT_RUN，不据结构结果宣称已有运行保护。BE/Tustin/ZOH 仍是字典型实现，待独立改造；原 51 字段 Params 总线草稿本轮不采用、未验收。

通用流程为 **TF 或 SS 资料 → 参数化 MATLAB 离散化脚本 → 脚本快速仿真门禁 → 信号定义及信号/复位/参数接口合同 → Simulink → 后续验证门禁**。按算法选择适用方法；一般模型不强制四方法或 SOGI 字段。允许数学常数 0/1/2π，不能把可配置参数或派生系数硬编码。可按方法直接展开物理参数差分，不强制所有方法输入离线 Ad/Bd/Cd/Dd。下述数值测试均为后续规范；本次先改 FE 结构是用户授权的执行例外，不表示新 preflight 已运行或 PASS。

## 1. 来源与方程合同

采用 [TI C2000Ware Digital Power SDK 5.03.00.00：SPLL_1PH_SOGI](https://software-dl.ti.com/C2000/c2000_apps_public_sw/c2000ware_sdk/digitalpowersdk/5_03_00_00/html_guide/group__SPLL__1PH__SOGI.html) 中的连续 SOGI 双输出传递函数。只采用其正交信号发生器部分，离散状态实现由下述方程独立推导。

\[
\tag{S1}D(s)=\frac{k\omega_0s}{s^2+k\omega_0s+\omega_0^2},\qquad
Q(s)=\frac{k\omega_0^2}{s^2+k\omega_0s+\omega_0^2},\quad \omega_0=2\pi f_0.
\]

取物理状态 `x1 = D`、`x2 = Q`，则

\[
\tag{S2}\dot x=Ax+Bu,\qquad y=x,\quad
A=\begin{bmatrix}-k\omega_0&-\omega_0\\\omega_0&0\end{bmatrix},\quad
B=\begin{bmatrix}k\omega_0\\0\end{bmatrix}.
\]

S1 是资料中的传递函数，S2 是据此选择的等价状态实现，属于推导参考，并非第二份独立资料来源。通用任务只提供 TF 或 SS 之一也可建模；若两者均有独立资料，则交叉核对并记录。

| 项目 | 方程合同与目标约定 |
|---|---|
| 输入 | `u`：有限标量，PU，`single`；测试通常在 ±1.2 PU 内 |
| 复位 | `reset`：标量 `uint8`，非零表示复位；优先于输出和状态更新，不重算参数 |
| FE 参数输入 | 独立的 f0/k/Ts 三个真实 single 端口；完整名称见第 3 节；其它方法接口待改造 |
| 输出 | FE D/Q、BE D/Q、Tustin D/Q、ZOH D/Q，8 个 `single` 标量端口 |
| 状态 | 每种方法 2 个固定维度状态；初值全零 |
| 参数 | `f0` / Hz、`Ts` / s、`k` / 无量纲，全部有限且大于零，`f0 < 1/(2Ts)` |
| 更新边界 | 每个离散采样点先读取当前状态和当前输入、计算输出，再保存下一拍状态 |
| 复位行为 | 复位采样点输出与下一拍状态均为零；释放后的第一拍严格遵循本方法的直通项 |
| 有效域 | 选用方法的双精度和 single 系数离散极点均须在单位圆内 |
| 异常策略 | 参数不合法在系数计算时拒绝；数学参考拒绝非有限输入；本模型的运行输入以有限值为接口前提，不附加硬件故障或估算器有效策略 |

中心频率处 `D(jω0)=1`、`Q(jω0)=-j`，因此 Q 相对输入滞后 90°。直流处 `D(0)=0`、`Q(0)=k`：Q 路会保留并放大直流偏置，不能将它作为直流抑制滤波器。

现有 `sogi_coefficients` 试验脚本先把基础参数量化为 single，再转 double 推导系数；FE 本轮直接用 single 物理参数端口展开差分，矩阵系数仍用于数学参考与旧方法方案，字典作为外部基准保存。有效设计周期为 `double(single(Ts))`，后续必须与实例编译调度一致。独立参考使用相同有效基础参数和量化输入，避免把接口量化差异混入离散化误差。

## 2. 离散化推导及状态含义

离散数学参考统一写为

\[
\tag{S3}\xi[n+1]=A_d\xi[n]+B_du[n],\qquad
y[n]=C_d\xi[n]+D_du[n].
\]

以下记 `h = Ts`、`I = eye(2)`。离线脚本推导矩阵作为参考；采用矩阵系数接口的方法在仿真前统一计算系数。FE 允许从 f0/k/Ts 直接展开差分，不要求矩阵作为输入。算法模块只做标量乘加、延时和复位选择，不在实时路径求逆或求矩阵指数。

`sogi_coefficients(f0,Ts,k)` 与 `sogi_reference` 是已有参数化计算/回放试验入口。拟采用 `run_sogi_preflight(f0,Ts,k)` 整理脚本门禁：不加载 SLX/SLDD，核对 S1 与推导的 S2，比较适用离散方法的响应、极点和频响。只有实际执行并通过后才把方程、系数关系、状态时序和参数快照用作建模参考；这里不声明该入口已完成验收或本次 preflight 已 PASS。

### 前向欧拉 FE

\[
\tag{FE}A_d=I+hA,\quad B_d=hB,\quad C_d=I,\quad D_d=0.
\]

此时 `ξ[n] = x[n]`，先输出当前物理状态，再用当前输入作显式更新。本轮 FE 直接实现 `Dnext = D + Ts*2*pi*f0*(k*(u-D)-Q)`、`Qnext = Q + Ts*2*pi*f0*D`；Q 更新使用当前 D，不能使用刚算出的 Dnext。极点为 `1+hλ(A)`；连续稳定并不保证前向欧拉稳定。在本例 `k=√2` 下，稳定条件是 `hω0 < √2`，因此 5 ms 扫描点失稳。

### 后向欧拉 BE

定义 `M=(I-hA)^(-1)`。从隐式递推 `x[n]=x[n-1]+h(Ax[n]+Bu[n])` 解出当前物理状态：

\[
\tag{BE}A_d=M,\quad B_d=hMB,\quad C_d=M,\quad D_d=hMB.
\]

在 S3 中 `ξ[n]` 保存前一拍物理输出状态；`y[n]=Mξ[n]+hMBu[n]` 就是本拍求解后的物理状态，随后令 `ξ[n+1]=y[n]`。直通项不可删除，否则会人为多出一拍延迟。启动时将虚拟前拍状态置零，首拍输入按完整后向欧拉步计入。

### Tustin / 梯形法

定义 `N=(I-hA/2)^(-1)`。对整个系统使用 `s=(2/h)(z-1)/(z+1)`，采用以下辅助状态实现：

\[
\tag{TU}A_d=N(I+hA/2),\quad B_d=hNB,\quad C_d=N,\quad D_d=\tfrac h2 NB.
\]

输出物理状态与辅助状态关系为

\[
\xi[n]=(I-hA/2)y[n]-\tfrac h2 Bu[n].
\]

因此 `ξ` 不能直接与 FE/ZOH 的物理状态比较。独立参考不用这组辅助矩阵，而直接计算

\[
x[n]=N\big((I+hA/2)x[n-1]+\tfrac h2B(u[n-1]+u[n])\big).
\]

复位同时清除 `x[n-1]` 与 `u[n-1]`；首个非复位样本采用当前输入的半步权重。当前模型使用普通 Tustin，没有中心频率预畸变。[MathWorks 连续—离散转换说明](https://www.mathworks.com/help/control/ug/continuous-discrete-conversion-methods.html) 说明了 Tustin 的频率映射及预畸变选项。

### 零阶保持 ZOH

\[
\tag{ZH}\exp\left(h\begin{bmatrix}A&B\\0&0\end{bmatrix}\right)
=\begin{bmatrix}A_d&B_d\\0&1\end{bmatrix},\quad C_d=I,\quad D_d=0.
\]

`ξ[n]=x[n]`，输入在 `[nh,(n+1)h)` 内保持不变，模型输出是该区间开始时的物理状态。用增广矩阵指数避免要求 A 可逆。独立参考使用 Control System Toolbox 的 `c2d(...,'zoh')`，没有复用系数函数中的矩阵指数实现。

比较连续正弦频响时，ZOH 方法包含采样保持造成的幅相差异；这与“对分段恒定输入精确匹配连续系统采样点”的定义不矛盾。不能通过平移结果消除该差异。

### FE 正式参数接口

通用算法可以选择独立参数端口或类型化总线，必须将参数数值作为明确输入。本轮 FE 采用 `u/reset/f0/k/Ts -> D/Q`，五个实际输入按以下顺序排列：

| 端口 | 类型/单位 | 作用 |
|---|---|---|
| `Input_PU` | single 标量 / PU | 当前输入 u |
| `Reset_States` | uint8 标量 | 非零复位 |
| `Cal_SOGI_F0_Hz_f32` | single 标量 / Hz | 中心频率 f0 |
| `Cal_SOGI_K_f32` | single 标量 / 无量纲 | 增益 k |
| `Cal_SOGI_Ts_s_f32` | single 标量 / s | 差分周期 Ts，必须等于外部实例调度 |

输出为 `InPhase_D_PU` 和 `Quadrature_Q_PU`，均为 single 标量 PU。FE 状态就是物理 D/Q，核心从真实端口按下式展开：

```text
Dnext = D + Ts * 2*pi * f0 * (k * (u - D) - Q)
Qnext = Q + Ts * 2*pi * f0 * D
```

使用 single 的 Product、Sum、常数 2π Gain、Unit Delay 等基础模块；三个参数必须实际参与计算，不得保留假端口或在核心中改读字典系数。先输出当前状态，再保存下一状态；reset 优先，复位时输出和下一状态均为零。不得用 Dnext 更新同拍 Q。

比较模型增加 f0/k/Ts 三个外部输入并驱动 FE；验证模型在核心外用字典 Constant 接入这三个输入。旧方法的字典系数方案保持待独立改造状态，不能据此声明四方法都已参数化。原 `sogi_parameter_bus(cfg)`、`sogi_parameter_bus_type` 的 51 字段方案仅为未验收草稿，本轮不使用。

核心不得通过 `evalin`、`slResolve`、直接查询 SLDD 或全局绑定 Gain 取得参数；字典类型定义允许。离线 MATLAB 仍负责参数化推导及独立参考，选择直接物理差分时不强制离线 Ad/Bd/Cd/Dd 输入；选择派生系数接口时，系数必须统一生成、只读、不独立手调。

各实例必须独立拥有状态、reset 和参数输入。参数仿真前提供、运行期间冻结，reset 不重算参数、不影响其它实例。核心 Unit Delay 继承外部实例采样周期；Ts 真实参与差分数值运算，但不控制运行调度。改变 Ts 必须停止、重新离散化并重新编译；值必须等于外部实际编译采样周期。

后续外部配置/包装层须只读校验实际输入的类型、有限性、f0/k/Ts 正值、Nyquist、选用方法稳定性和周期一致性；若输入派生系数，还须核对其一致性。**该 FE 实际输入校验尚待实施/验收，当前不能宣称已有运行保护。** 旧字典值检查不是端口校验；若扫描需确认方法停用，应检查编译活动状态，不能由保存的 Commented 推断。[CompiledIsActive 官方说明](https://www.mathworks.com/help/simulink/slref/block-parameters-and-properties.html)

### 信号定义合同（本轮补规则，未验收对象绑定）

先定义信号再接线。分类包括外部输入、输出、中间量、状态、控制/复位、物理参数信号和派生系数。正式接口、共享、状态及记录信号必须有定义；纯局部连线可由公式映射说明，不强制每根线建立对象。SOGI 定义示例如下，完整记录模板见 [MODELING_RULES.md](MODELING_RULES.md)：

| 信号/简图名 | 含义、时序及名称映射 |
|---|---|
| `Input_PU / u[n]` | 当前采样输入，single 标量 PU；完整输入名映射为 `Meas_SOGI_In_PU_f32`，由外部输入生产、FE 消费 |
| `Reset_States` | 当前拍控制输入，uint8 标量、非零有效；优先清零输出与下一状态，记录外部生产者 |
| `f0 / k / Ts` | 三个 single 标量物理参数信号，对应第 3 节完整 Cal 端口名，单位 Hz/无量纲/s；仿真前提供、运行冻结，Ts 与编译调度一致 |
| `InPhase_D_PU / D[n]` | 当前拍物理同相输出/状态，single 标量 PU；保留既有 `Meas_SOGI_FED_PU_f32` XCP 名 |
| `Quadrature_Q_PU / Q[n]` | 当前拍物理正交输出/状态，single 标量 PU；连续标准 SOGI 在中心频率相对输入滞后 90°，FE 离散相位待数值验证；保留 `Meas_SOGI_FEQ_PU_f32` XCP 名 |
| `Dnext / Qnext` | single 标量 PU，由复位选择后的当前输入/状态计算并写入 Unit Delay；复位有效且参数有限时为零。零初值属于延时保存状态，不要求任意首拍候选为零 |
| 局部中间量/派生系数 | 明确对应方程项、生产者/消费者与单位；FE 直接用物理参数差分，旧方法的离线系数另列，不能混为状态 |

每项还须记录实例角色、单位/参考正方向/坐标系/PU 基准、类型/维度/范围、采样时间/速率/拍次和延迟、生产者与消费者、初值/复位、valid/失效/NaN 政策及记录/XCP 暴露。SOGI 输入与 D/Q 共用 PU 基准，复用实例应注明其对应物理基准；范围元数据不等于限幅、断言或有效性保护，异常行为由算法合同决定，不任意增加限幅或 valid 端口。Cal 名称的端口仍是信号输入，不变成字典直读的数值参数。

1 PU 是本试例输入幅值，不是通用量程；u、D/Q 和状态不能机械限定为 [-1,1]，范围由工况合同确定，未确定填写“待定”，不能宣称范围门禁 PASS。

需要统一类型、单位、范围、记录或代码接口的信号，在独立 SLDD 中定义 `Simulink.Signal`，记录实际线名与对象同名映射并显式绑定/解析；对象存在不代表已绑定。采样时序等在端口/块配置和合同中定义，不承诺全部合同属性都在 Signal 对象中。字典类型和元数据不替代核心参数端口。同作用域每个命名信号只有一个生产者，实例状态与实参独立，同名全局对象不能令实例共享状态。

`Simulink.Parameter` 保存外部标定值，`Simulink.Signal` 定义信号属性，不能互相覆盖。分别记录端口显示名、实际线名、对象名和类别；显式解析时线名匹配 Signal 对象名。已有 Cal 同名 Parameter 时另取唯一信号对象/线名，保留 Cal 端口及 XCP 标识，不把端口强制绑定到错误类型。

后续按定义接线/绑定，再编译核对传播后的类型、维度、采样周期及实际解析对象。本轮不要求改动实际模型或信号对象；上述新增核查为 NOT_RUN，原结构/编译检查不能作为新信号合同及对象绑定已验收的证据。

### 功能命名

名称和接口必须使读者判断功能及角色，无需打开核心内部。名称与紧邻注释可共同解释数学意义，不强制基本块堆砌超长名称；但默认编号和孤立矩阵下标不能作为最终名称。

| 对象 | 目标规则 | 建议名称 |
|---|---|---|
| 模型文件 | `<algorithm>_<function>_<role>.slx` | `sogi_dual_output_filter_discrete.slx`、`sogi_dual_output_filter_validation.slx` |
| 方法子系统 | 算法 + 功能 + 适用离散方法 | `SOGI_DualOutput_Filter_FE`、`SOGI_Filter_Tustin` |
| 基本块 | 运算/状态角色，必要时附用途 | `Weight_State1_For_D`、`Sum_D_Output`、`Update_State1`、`Delay_State1` |
| 复用实例 | 按实际应用角色区分，不只编号 | `SOGI_Voltage_Alpha`、`SOGI_Current_Beta` |

同一作用域名称唯一。A11、Bd 等保留为参数符号或公式映射注释；Tustin 辅助状态必须与物理状态区分。角色、单位、方法按辨识需要加入，不重复堆砌。可复用模型名称不固化可配置的频率、增益或采样周期数值，具体值记录在实例配置及试验数据中。XCP 完整名称保持，不能为了长名缩小字号。本轮只在授权 FE 结构范围内采用上述方法名及内部功能名，更新相关依赖；模型文件及其它方法的全面改名待后续实施。

### 图面规则

用户随后授权按规则调整，本轮已对两个 SOGI 模型的七个图层实施端口感知定尺与重新布线；见 [本轮布局记录](reports/port_aware_layout/layout_review.md)及其中的逐块数据和最终图。未运行编译或数值仿真。先前 FE 紧凑调整见 [历史记录](reports/fe_compact_layout/layout_review.md)，历史结果与本轮结果分开。

完整细则见 [MODELING_RULES.md 第 4.1–4.7 节](MODELING_RULES.md)，块类型尺寸详表见其中第 4.2 节。普通信号按输入→预处理→算法→后处理/误差→输出固定列序右行，支路上下分行；local 标签不能掩盖生产/消费区域倒置。状态反馈在下方独立区明确标识；连续状态输出打包属于前向后处理。信号、reset/控制、物理参数输入分行。

SOGI 目标统一 Arial 14 pt，通用下限 12 pt。矩形运算块宽至少 120 px，标准符号块至少 40 px，Unit Delay 至少 70 px，SOGI 方法子系统至少 300×170 px（原 165 向上对齐 10 单位网格）。长名称扩大空间，完整标签和文字不得遮挡；线段只允许水平/垂直，不能穿越无关块。还必须检查不同信号线相交、共线重叠和 T 形假连接，复位、零值等不同信号使用分离通道。编辑器默认 100% 并可滚动，导出图另行复核。层级块默认关闭内部预览，进入内部看方程，避免缩略图覆盖端口名称。[内容预览官方说明](https://www.mathworks.com/help/simulink/ug/preview-content-of-hierarchical-items.html)

端口感知尺寸采用模型坐标网格 g=10：短符号基本块端口基准节距 20，显示完整命名端口的层级块 40，文字净距 10，层级内边距 20。nL/nR 按可见物理连接口计数，向量/Bus 的一个口仍计一个；顶部/底部控制接口按实际位置与类型另留空间，不能因名称叫 reset 就把普通 Inport 算作顶部控制口。Arial 14 pt 不等于 14 px，保留字号并在同一坐标尺度测量文字。

字号、类别最小尺寸、文字净距和最低端口节距属于项目验收要求；公式与列间/通道间隙是可修正的设计起点，特殊块型偏离须记录并单独审阅。块体使用网格，连线仍接真实端口坐标，不强迫端口对齐网格。全局对齐必须保留算法实际复位位置、操作数及当前/下一拍关系，不能用固定列名规定执行时序。

令 `N=max(nL,nR)`；N=0 时 `Hport=0`，N≥1 时 `Hport=mt+mb+(N-1)*p`。初算采用 `H=ceil10(max(Hmin,Hport,Hinside))`、`W=ceil10(max(Wmin,2*mx+L+C+R,Wtop,Wbottom))`，ceil10 表示向上对齐 10 单位网格。L/R 只计内部显示的左右端口标签实测最大宽度，C 为中央符号/留白（层级默认 80），外部块名独立计占位，不重复撑大块体。公式仅是起点，必须回读真实端口位置并迭代净距，0/1 口情况不得产生负间距或除零。

仅同功能、同端口签名、同显示形式的组按组内最大 W/H 统一；不同口数可分子组共享列基线或必要宽度，不能用八口块放大全部单口块。列宽/行高包含块体、全部外部文字与控制接口包围框，布线通道另留。常规水平间隙基本块 60、层级块 100，转弯通道 20、垂直组间 60，均为项目初始值，须按实际碰撞调整，并非 MathWorks 硬限制。

列宽、行高取端口/基线对齐后占位框的横向/纵向投影并集，不只取单个块宽高的最大值；据此安排列位置与行位置，避免漏掉偏移的长名称或控制口。

实际应用中须回读 Simulink 最终 Position，防止端口自动分布将请求坐标调整离开网格；线端以 PortConnectivity 的连接位置和端口身份核对，不硬编码 PortHandles 显示坐标的偏移。独立平行通道需检查实测净距，本轮采用 20 px，不以 1 px 错开冒充可读。命名线在转折前预留实测标签宽度及 20 px 余量，并逐条检查后续线段不穿字；缺少标签位置的自动项保留 NOT_RUN，最终图面人工证据单列。

120/40/70 px 的矩形/Sum/Unit Delay 宽度和本例 Arial 14 pt 是可读下限，不是全图等比例放大目标。先缩短过量空白和线长，块按内容适配尺寸，按方程功能成行成组，相关操作就近，说明紧贴对应区域。普通流仍从左到右，禁止蛇形折返伪装顺序；默认 100% 下允许滚动，但不能用极大画布代替便捷审阅。

单个方程组尽量在常用审阅窗口完整追踪，仍过宽才考虑接口清楚的功能层次，本轮不默认改变拓扑。人工同时检查整体可扫读与局部全文清晰，记录前后绘图区宽高、缩减及同缩放截图；几何 PASS 不能替代审阅便捷性，新坐标不作为通用固定目标。

加法、乘法等满足交换律时，按来源上下顺序选择输入端口，避免上方参数跨越主信号；交换后核对方程映射。减法、除法及矩阵运算不能为美观交换操作数顺序。

已有 620×480 的 Four_Methods 和固定位置模板只描述旧接口布局；加入三个真实物理参数端口和功能名称后需重新核查，不能宣称新目标现已符合。Inport/Outport 保留标准形状，名称留白单独检查；同功能、端口签名和显示形式的分支才同组统一尺寸；不同组通过列基线和行布局协调。所有作用域都要单独人工检查名称、语义顺序、文字留白和预览干扰，自动块避障 PASS 不包含线间关系检查，不能替代人工审图。

## 4. 后续流程与验收计划

**本轮 FE 结构已实施，结构/编译接口检查为 213 PASS、0 FAIL，见 [修改记录](reports/fe_physical_inputs/change_record.md)。实际 FE 输入校验、数值仿真及双实例回放均为 NOT_RUN。** 不据此声明 preflight 或数值验收通过；线间关系与人工图面检查须有独立记录。 通用流程的“必须”门禁及记录模板见 [MODELING_RULES.md](MODELING_RULES.md)。具体脚本入口在后续实施时按版本确认；SOGI 函数名不是其它算法的固定依赖。

1. 整理 TF 或 SS 资料、单位、初值、保持假设和时序，区分独立资料与推导参考；选择适用离散方法并记录理由。
2. 用物理参数、Ts、方法作为 MATLAB 脚本输入，先离散化和快速仿真，不依赖 SLX/SLDD。设定容差并检查适用的稳定性/响应/频响；实际通过才进入建模。SOGI 四方法基准须四者稳定，FE 失稳探索记录并跳过，不能算基准通过。
3. 在建模前填写信号定义及接口合同：逐项记录类别/含义、全名与简图名、单位/参考方向/坐标/PU 基准、类型/维度/范围、拍次/延迟、生产者/消费者、初值/复位及 valid/失效/NaN、记录/XCP 政策，确定对象与显式绑定方案后再接线。信号/reset/参数/输出可用独立端口或总线，本轮 FE 已选三个真实物理参数端口；区分物理与派生参数，声明实例隔离、运行冻结、Ts 与调度一致性及外部校验责任。
4. 按通过的脚本和合同建立 Simulink 基础运算模型，并按功能命名文件、子系统、基本块及实例；配置数值经输入进入核心。外部包装层提供基准 Source，不能用蓝色面板或全局 Gain 代替接口。
5. 新增端口、改名、字体变更或 Bus 端口展开后，依次重算“块→组→列行→路由→结构/图面检查”，回读实际端口间距；先压缩过量空白和线长、就近分组方程及说明，保持字号、可读尺寸和左到右顺序；完成结构及编译核对：传播后的信号类型、维度、采样周期与定义一致，核实实际对象绑定，不能用对象存在或范围元数据代替解析/约束证据；完成接口、功能命名及全部作用域人工图面检查；名称加接口说明功能，注释补足公式映射。逐线检查不同信号相交、共线重叠、T 形假连接及复位/零值通道分离；交换律允许时按上下位置选端口，但不得改变减法、除法及矩阵操作数顺序。同步检查整体可扫读、方程组完整追踪与局部全文清晰，保存前后绘图区尺寸/缩减和同审阅缩放截图。未覆盖项目记 NOT_RUN，自动块避障 PASS 不能替代线间检查或人工审阅便捷性。
6. 后续再运行模型逐拍回放和复用验证：同一参数/输入/初值/时序，不平移时间轴；至少两个同时存在的不同参数实例和独立复位，检查互不影响。修改 Ts 时停止、重离散化、重编译；校验实际输入快照及周期不匹配时的拒绝行为。
7. 归档参数化脚本、选择理由、接口与命名映射、参数/类型版本、测试输入与原始输出、误差指标和实际状态；尺寸记录包含端口数 N、标签 L/R、初算及实测 W/H、实际最小端口间距、组 ID、占位框与偏离理由；每份报告只证明其实际执行范围。

本轮布局流程另要求：应用后回读块体网格及连接端点，逐段检查所选平行通道间距；给全部命名线留出标签段并人工复查。清除临时查找高亮后再导出，分别保存自动结果与线标签人工记录。旧固定坐标脚本（包括旧 FE 布局入口）属于历史方案，直接运行会覆盖新坐标；当前复现按 [本轮记录](reports/port_aware_layout/layout_review.md)中的量测、model_edit、路由与检查步骤进行。

### SOGI 后续测试建议

以下保留原试例测试设计，属于后续计划，不是完成结果；通用模型按算法选择指标。

| 工况 | 目标判定 |
|---|---|
| 脚本预验证 | TF/推导 SS 一致，参数化响应/极点/频响有证据；选定四方法基准全部稳定 |
| 零、阶跃、正弦、固定随机输入 | 模型与独立差分参考逐拍比较，含非零激励实际进入核心的检查 |
| 两段运行中复位 | 当前实例有效状态及输出按合同归零，释放后与参考一致，不触发参数重算 |
| 双实例不同合法参数输入、独立 reset | 参数、状态和复位互不影响；不以单实例顺序改参代替 |
| 参数/类型/派生一致性及 Ts 失配 | 外部输入校验拒绝非法完整快照，运行参数冻结，Ts 不改变实时调度 |
| 50 Hz 基准 | 最后 0.2 秒拟合；原目标为幅值误差≤2%、相位误差≤1° |
| 40/50/60/150/250 Hz，幅值/相位变化及谐波 | 仿真与自身离散理论比较，另报告相对连续系统的离散化差异 |
| 0.1 PU 直流偏置 | D 直流接近零，Q 直流接近 0.1k，避免误判 Q 为直流抑制器 |
| Ts 探索 | 先稳定性判定，仅回放稳定候选；跳过原因单列，不当作 PASS |
| 外部配置保护 | 非法或运行/Fast Restart/既有未保存更改时拒绝写入，面板仍显示字典真实状态 |

原 SOGI 逐拍容差建议为 `abs(error) <= 5e-5 + 5e-5*abs(reference)`，自身离散频响拟合目标为幅值误差 `<=2e-4+2e-4*abs(Hd)`、相位误差 `<=0.05°`；新的参数接口实施时须确认这些容差与数据类型和工况匹配，再记录实际结果。连续参考精度应独立收紧并检查收敛，不能用相似波形替代数字证据。
