# SOGI 按端口与文字定尺实施记录

日期：2026-09-10。依据：[建模规范 §4.1–4.7](../../MODELING_RULES.md#41-定尺输入单位与项目基准)。本轮按用户“按照上述调整”实施几何修改，范围为两个 SOGI 试例模型的 7 个作用域、275 个块、233 条现有信号连接。尺寸、坐标、注释位置和路由已应用；不把前一轮只修订规范的状态当作本轮结果。

本记录基于 [before.json](before.json)、[after.json](after.json) 和 [checks.json](checks.json)。自动快照检查为 **5012 PASS、0 FAIL、16 NOT_RUN**；16 项均为没有导出实际坐标的线标签包围框。7 个作用域的 Simulink `model_read` 均返回 `status: ok`，`model_check` 均返回 `status: healthy`，原始输出见 [structural_tools.json](structural_tools.json)。主任务逐张审查最终导出图，人工图面审阅为 **PASS**；这不改写缺少实际线标签坐标的自动 NOT_RUN。本轮没有运行编译、数值仿真或双实例验证，均为 **NOT_RUN**。

## 2. 定尺与全局匹配的实际结果

所有尺寸均为模型坐标，不能直接与高分辨率 PNG 像素等同。字体保持 Arial 14 pt，块体使用 10 单位网格；连接端点按真实端口坐标设置，端口坐标允许不在该网格上。编辑器 Zoom=100% 已设置并回读；本轮没有拍摄原生编辑器屏幕，不把缩放属性回读描述为编辑器截图审阅。

### 2.1 层级块

端口节距取同侧相邻实际端口坐标之差的最小值；只有一个端口时记“不适用”，不填零。下列端口是实际图面连接数，不是信号向量元素个数。所有这些层级接口均位于左右边，顶/底无实际控制接口。

| 所在作用域/块 | 左入/右出 | 原 W×H | 现 W×H | 原最小左/右节距 | 现最小左/右节距 |
|---|---:|---:|---:|---:|---:|
| 比较顶层 / `SOGI_DualOutput_Filter_FE` | 5 / 2 | 900×600 | **390×240** | 120 / 300 | **50 / 120** |
| 比较顶层 / `BE` | 2 / 2 | 900×600 | **300×180** | 300 / 300 | 90 / 90 |
| 比较顶层 / `Tustin` | 2 / 2 | 900×600 | **300×180** | 300 / 300 | 90 / 90 |
| 比较顶层 / `ZOH` | 2 / 2 | 900×600 | **300×180** | 300 / 300 | 90 / 90 |
| 验证顶层 / `Four_Methods` Model Reference | 5 / 8 | 900×601 | **580×420** | 120 / 75 | **85 / 50** |
| 验证顶层 / `Continuous_Reference` | 1 / 1 | 300×140 | **200×80** | 不适用 / 不适用 | 不适用 / 不适用 |

FE 左侧最大标签宽度为 145，右侧为 121；使用两侧各 20 和中央 80 的留白，宽度初算为 `ceil_10(40+145+80+121)=390`。五输入按 40 节距、上下各 20 初算高度为 200；实施取 240 后读取真实端口，最小左节距为 50，满足 40 的要求。保留全部 `f0/k/Ts` 输入与完整名称，没有为了缩小方框把它们合并成总线。

`Four_Methods` 左/右最大标签宽度分别为 155/193，内部模型名宽度为 167；中央区域按 `max(80,167+20)=187`，故宽度为 `ceil_10(40+155+187+193)=580`。八输出的高度公式给出 320 的起点；实际采用 420，为上游参数 Constant 的块体、外部名称及接入行保留空间。读取后的最小输入/输出节距分别为 85/50。宽高没有照抄 FE。

BE/Tustin/ZOH 同属 `SubSystem_2_2_right` 组，采用共同 300×180。FE 为 `SubSystem_5_2_right` 单独分组；端口数不同，未强制共用相同高度。旧方法的历史下限 300×165 已由规范转为 300×170，实际采用 180 以保持 Simulink 归一化后的位置与尺寸落在网格上。

### 2.2 基本块与接口组

| 类型/所在组 | 实际尺寸 | 定尺与分组理由 |
|---|---:|---|
| Gain、矩形 Product、普通 Constant、类型转换 | 120×40 | 单独按运算类型和端口签名分组，保持符号及内容空间 |
| 三个外部物理参数 Constant | 170×40 | 完整 Cal 表达式进入块内宽度计算，作为物理参数显示组独立定尺 |
| 双输入 Sum | 40×40 | 保留标准运算符形状 |
| 三输入矩形 Sum | 40×80 | 按实际三输入节距增加高度，不将所有 Sum 一律放大 |
| 三输入 Switch | 120×80 | 包含中间控制输入；读取实际端口而非只依赖理论高度 |
| Unit Delay / 本例 Integrator | 70×40 | 保留标准状态符号，完整状态名另计外部占位 |
| Inport / Outport | 30×20 | 保留标准端口外形，名称不塞入块体 |
| Goto / From | 宽 100、120、130 或 140，高 30 | 按各作用域标签长度取本组共同宽度；没有把最长标签尺寸扩散到全图 |
| 验证顶层 4 路 / 8 路 Mux | 20×280 / 20×400 | 保留窄条，按实际来源行和连线间距定高 |
| 连续参考内部 2 路 Mux | 20×200 | 保留窄条并匹配两条状态输出行 |

| Scope | 120×60 | 按显示接口类型独立处理 |

快照中共检查 65 个作用域内可比组，组内尺寸一致。组 ID 按块类型、实际端口签名、方向划分；物理参数 Constant 增加显示角色区分。完整逐块类别、组、标签量测、初始尺寸和计划位置见 [layout_plan.json](layout_plan.json)，应用后的端口位置和最终尺寸以 [after.json](after.json) 为准。

## 3. 路由与检查证据

按块、外部名称及注释占位重新路由现有连接；独立信号不共用路径。源/目的使用 `PortConnectivity.Position`，端口节距使用真实 `PortHandles.Position`。两者可能因输入箭头长度不同而不相同，端点检查没有通过增加误差容限掩盖偏差。

首版导出审查发现命名线转折可能穿过文字，以及四方法各两处控制竖通道仅相隔 1 单位。本轮已修正：16 条命名线在首个转折前为完整标签留出水平段；控制/零值独立通道重新分开。路由器增加不同信号平行段的 20 单位间距约束，检查器新增对应 233 项检查且均为 PASS。最终导出图中已逐一确认上述文字与通道修正；自动线标签边界仍为 NOT_RUN，不以人工结论填补缺失坐标。

## 4. 可复查材料与操作顺序

[打开同字号前后布局对照](review.html)：可选择七个图层、缩放和分别滚动；before 图按 0.72 映射到 after 的 72 dpi 显示基准，不改变原始图像。

本次工具链分阶段执行，不存在一个脚本一键应用所有布局并自动证明验收通过。

1. 加载并确认两个 SOGI 模型停止，运行 `sogi_capture_port_layout('before')` 记录初始块、端口、连接、配置及文字度量。编辑前按仓库 Git MCP 要求检查状态和相关差异。
2. 运行 [plan_sogi_port_layout.py](../../plan_sogi_port_layout.py)，由当前 `before.json` 生成单块/分组计划与 `configure_1.json` 至 `configure_7.json`。脚本只生成配置操作，不修改模型。
3. 对每个作用域分别通过 Simulink `model_edit` 应用对应 configure 操作。读取实际端口后运行 [sogi_finish_port_layout.m](../../sogi_finish_port_layout.m) 整理注释和 100% 编辑器缩放，生成 `align_1.json` / `align_6.json`；再通过 `model_edit` 应用这些对齐操作。
4. 重新捕获实际几何为 `route_input.json`。运行 [route_sogi_port_layout.py](../../route_sogi_port_layout.py) 生成 `routes.json`，如需局部位置修正则检查并应用 `adjustment_operations.json`，随后重新读取实际端点，不能仅修改离线快照冒充模型变更。
5. 运行 [sogi_apply_port_routes.m](../../sogi_apply_port_routes.m)。它先核对现有连接的源、目的及线名，只写入折线路径和线字体；不会删除重建或改变数学连接。
6. 对每个作用域执行 `model_read` / `model_check`，保存模型；捕获 `after.json`，用 [check_port_layout.py](../../check_port_layout.py) 比较 before/after 并产生 `checks.json` / `checks.csv`。此检查读取快照，不编译或仿真模型。
7. 通过 [sogi_export_port_layout.m](../../sogi_export_port_layout.m) 导出各作用域，回读编辑器 100% 缩放设置并审查完整导出图；分别记录原生编辑器实拍是否执行。本轮实际审查覆盖导出图，未拍摄原生屏幕。明确记录线标签、名称全文、语义流向、全局匹配及未完成项。

前后各作用域图片按上表序号对应 `before_1.png`—`before_7.png` 与 `after_1.png`—`after_7.png`。原 before PNG 受 MATLAB 文件写入保护影响，外部查看器不能直接读取，另提供 `before_view_1.png`—`before_view_7.png` 正常查看副本。before 使用 `-r100`，after 使用 `-r72`，二者原图导出分辨率不同；本报告的宽高与缩减比较均依据模型坐标，不按图像像素比例计算。人工前后对照时，before 图片须按 0.72 映射至同一 72 基准，再结合全尺寸文件检查文字。`after_raw_1.png`—`after_raw_7.png` 保留 after 的原始导出文件；raw 表示未经查看副本处理，不表示与 before 相同分辨率。展示缩放不代表模型字体已改变。
