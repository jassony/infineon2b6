# SOGI 状态方程离散建模合同

本次在 `SOGI_state_space_test` 建立独立试例。首个完整 Simulink 基线采用前向欧拉（FE）；参数化 MATLAB 参考另比较 FE、BE、Tustin、ZOH。旧目录中的 SLX、SLDD 和已记录的 FE 结构结果均不作为本次新模型的验收证据。本文件记录设计合同，执行证据由本目录的新报告给出，未运行项目不得标记 PASS。

## 1. 来源、方程与方法

来源是用户确认的标准 SOGI 连续状态方程；连续传递函数由该状态方程推导，属于同源交叉核对，不是独立资料。

\[
\dot x=Ax+Bu,\quad y=x,\quad
A=\begin{bmatrix}-k\omega_0&-\omega_0\\\omega_0&0\end{bmatrix},\quad
B=\begin{bmatrix}k\omega_0\\0\end{bmatrix},\quad \omega_0=2\pi f_0.
\]

`x=[D;Q]` 为同相、正交物理输出；中心频率处 Q 相对输入滞后 90°。输入、D、Q 使用相同 PU 基准和参考方向；本试例只定义无量纲幅值 1 PU，未指定电压或电流的 SI 基值，不能据实例角色名进行未经约定的 SI 换算。标准 Q 路直流增益为 k，不能要求其抑制直流。

基准为 f0=50 Hz、k=√2、Ts=50 μs、零初始状态。参数化脚本使用 double 物理参数；模型实际输入为 single，模型对照参考须使用这些 single 实参再转 double 的同一快照。离散模型按 t[n]=n·Ts 执行，输入在两个采样点间保持不变。

令 `r=2*pi*f0*Ts`。FE 保留物理 D/Q 状态，无状态坐标变换：

```text
若 Reset_States ~= 0：u_eff = D = Q = 0
否则：u_eff = Input_PU，D/Q = 当前 Unit Delay 状态
输出：InPhase_D_PU = D；Quadrature_Q_PU = Q
Dnext = D + r * (k * (u_eff - D) - Q)
Qnext = Q + r * D
下一拍 Unit Delay 状态 = [Dnext; Qnext]
```

有限合法参数是仿真的前置条件，因此复位时乘法不会产生 `0*Inf`。复位期间输出和写入的下一拍状态均为零；参数不被复位、重算或改写。零初始状态不意味着普通首拍的 Dnext 必须为零。BE/Tustin 的辅助状态与物理输出不同，参考比较只比输出与各方法理论，不能直接比较内部状态。

FE 用于首个模型，是因为其显式两状态更新能直接展示五输入接口及基础运算结构。其他三种方法在脚本中报告稳定性、频响与误差，尚不表示已有对应的新 Simulink 实现。FE 稳定条件由实际离散矩阵的极点检查确认，不用限幅隐藏发散。

## 2. 正式模型与接口

| 资产 | 功能与角色 |
|---|---|
| `sogi_dual_output_filter_fe_discrete.slx` | 可复用 FE 双输出离散滤波器，独立两状态 |
| `sogi_dual_output_filter_fe_validation.slx` | Voltage、Current 两个同时运行的 Model Reference 实例，用于隔离与复用验收 |
| `sogi_state_space_parameters.sldd` | 外部默认配置及信号元数据；不提供核心隐藏数值参数 |

算法模型端口顺序固定如下。参数通过真实连线参与差分方程，不允许只显示名称却不用其数值。

| 顺序/方向 | 端口完整显示名 | 类别与简图含义 | 类型/维度 | 单位/范围 |
|---|---|---|---|---|
| 输入 1 | `Input_PU` | 外部输入 u | single 实标量 | PU；有限，试例覆盖范围由工况给出 |
| 输入 2 | `Reset_States` | 控制复位 | uint8 标量 | 无量纲；0 不复位，1…255 复位 |
| 输入 3 | `Cal_SOGI_F0_Hz_f32` | 物理参数 f0 | single 实标量 | Hz；有限，0<f0<1/(2Ts) |
| 输入 4 | `Cal_SOGI_K_f32` | 物理参数 k | single 实标量 | 1；有限，k>0 |
| 输入 5 | `Cal_SOGI_Ts_s_f32` | 设计周期 Ts | single 实标量 | s；有限，Ts>0，须与实例调度匹配 |
| 输出 1 | `InPhase_D_PU` | 同相物理输出 D[n] | single 实标量 | PU；有限值验收，无任意限幅 |
| 输出 2 | `Quadrature_Q_PU` | 正交物理输出 Q[n] | single 实标量 | PU；有限值验收，无任意限幅 |

验证模型先排列 Voltage 的上述五输入，再排列 Current 的五输入；四输出顺序为 Voltage D、Voltage Q、Current D、Current Q。两个角色用于区分复用实例，不指定实际电压、电流基值。

## 3. 信号定义与绑定

所有接口、状态和记录量须能追溯到以下定义；纯局部算术线按方程映射定义，不强制创建独立 Signal 对象。

| 信号/数学符号 | 生产者 → 消费者 | 拍次、初值与复位 | 对象/记录政策 |
|---|---|---|---|
| u / `Input_PU` | 外部输入快照 → 复位选择、误差计算 | 当前拍；首拍取输入；有效复位时 u_eff=0 | 外部波形原样记录，保留 single 实际值 |
| reset / `Reset_States` | 外部 uint8 快照 → 输出/状态复位选择 | 当前拍、最高计算优先级；无固定首拍强制复位要求 | 全量记录；测试非 1 的非零值 |
| f0/k/Ts 的 Cal 端口 | 外部已校验常量快照 → 频率、步长和增益运算 | 仿真前确定并冻结；不设状态初值；复位不改写 | 字典中为 Parameter 基准；端口仍是参数信号，不强绑同名 Signal |
| r、k·(u_eff−D)−Q | 当前参数/物理量 → 状态增量 | 当前拍组合量；single；r 无量纲，后者 PU | 局部公式映射；不独立标定派生值 |
| D/Q 当前延时状态 | 各实例的 Unit Delay → 复位选择 → 输出/状态更新 | 初值 0；当前拍存储值；复位后的有效值为 0 | `State_SOGI_FED_PU_f32` / `State_SOGI_FEQ_PU_f32` 为状态元数据候选，须记录实际绑定 |
| Dnext/Qnext | Update_D/Update_Q → 各自 Unit Delay | 下一拍候选；有效复位时 0；Qnext 不得接到 D 的延时 | single、PU；与当前输出区分，必要时独立记录 |
| D/Q 输出 | 当前有效物理状态 → 算法 Outport → 验证记录 | 当前拍输出先于更新；无额外输出延时；复位输出 0 | 全名映射 `Meas_SOGI_FED_PU_f32` / `Meas_SOGI_FEQ_PU_f32`，分别对应 D/Q |

本试例不导出 A2L，也不添加固件 XCP 接口；上述 XCP 风格标识保留供后续映射。Signal 对象负责 single/标量等元数据，Parameter 对象保存外部默认值；同名对象类别不得混用。显式解析的实际线名必须等于对应 Signal 对象名，并核查解析来源。对象存在本身不构成绑定通过。多实例同名类型/元数据不得转成共享状态或共享可写参数。

模型不添加通用 valid 输出、限幅、NaN 替代或自动回退。外部包装层在仿真前拒绝错误类型、非有限输入、非法参数、调度不符与不稳定候选；尚未接受运行中任意参数更新。u、D/Q、状态的通用量程尚未定义，不能机械设为 [-1,1]，不得宣称通用幅值范围门禁通过；本次仅验收已列有限输入测试域。

## 4. 参数快照、实例与调度

`sogi_fe_simulation_input(model,t,inputSets,executionTs)` 接收实际波形及物理参数，为每实例分别构造固定参数 timeseries。每个快照具有 `u`、`reset`、`f0_Hz`、`k`、`Ts_s`；wrapper 校验类型、维度、有限性、范围、严格单位圆内极点和时间轴。参数 single 表示误差按明确浮点容差与 double 调度周期比较，不接受实际周期的有意义偏差。

核心 Unit Delay 继承实例采样周期；Ts 端口仅进入数学计算，不能设置运行调度。修改 Ts 必须停止仿真、重新生成参数化参考并检查稳定性、更新外部调度、重新编译。检查与复位不得写字典、参数或模型。禁止核心 evalin、slResolve、字典查询或全局 Gain 系数读取。

Voltage 与 Current 各有独立输入、参数、复位和状态。复用验收使用两个同时运行的实例，改变 Voltage 的输入/复位/参数后重跑，Current 同一快照的完整轨迹必须不变；单实例顺序调参不能替代此测试。

## 5. 命名、定尺和布局

基础块名表达数学角色，例如 `Compute_Frequency_radps`、`Compute_Sample_Step`、`Sum_Input_Error`、`Update_D_State`、`Update_Q_State`、`Delay_D_State`、`Delay_Q_State`。块名、注释共同给出方程映射，不能保留无法辨认功能的 FE/Gain1/A11 名称。

按现有规范 §4.1–4.7 逐层布局：普通路径左到右，参数独立行，状态反馈在下；Arial 14 pt，10 单位网格，按实际端口数、标签宽度、内外边距确定块体尺寸；可比块组统一尺寸，避免把所有块放大到同一最大外形。五输入/两输出层级接口须按五个输入端口的实际间距定高，不能复用旧两输入形状。

矩形运算块宽度至少 120、Sum 至少 40、Unit Delay 至少 70；命名端口间距至少 40，基础符号端口间距至少 20。实际布局须重新读回 Position 和 PortConnectivity，不能以请求坐标代替结果。线段正交、无穿块、无无关信号交叉/重叠/伪 T 接点；无关平行线投影重叠时至少留 20 单位间距。名称按全文占位，标注线首段按实测文本宽度另留 20 单位。默认 100% 缩放、禁用内容缩略预览，各作用域人工检查并导出可读图。

本次为新建模型，不虚构旧尺寸或缩减百分比。归档时记录最终绘图宽高、端口数量和实测间距、同组尺寸、占位/通道、各作用域截图及人工可扫读结论。
