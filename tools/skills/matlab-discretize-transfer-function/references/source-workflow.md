# 从资料到可执行方程的通用流程

此流程从用户提供的推导示例中提炼，适用于一般滤波器、控制器、观测器线性子系统或被控对象；不固定算法、阶数、物理参数名称和测试指标。

| 步骤 | 实际操作 | 输出与门禁 |
| --- | --- | --- |
| 1. 资料与符号表 | 记录每条方程、输入输出、单位、反馈方向、变体及假设 | 名称与完整公式一一映射 |
| 2. 连续系统整理 | 直接接收 TF/SS，或用 solve 消去内部量；串并联/反馈按定义组合 | 整体 TF 或 SS；直流、高频、阶次/相对阶次核查 |
| 3. 保留物理参数 | 建立 symbolic 表达式与假设，独立定义一组数值快照 | 原始符号模型与参数合同，不用数字覆盖符号 |
| 4. 方法分支 | 指定 Ts/保持方式/方法，对完整系统进行代换或状态积分 | Gd(z) 或 Ad/Bd/Cd/Dd；状态和输入时序 |
| 5. 化简与代换 | collect、simplifyFraction，提取公共子表达式，保留回代关系 | 简化式回代与原变换式等价；无遗留未绑定符号 |
| 6. 系数整理 | 转 q=z^-1、补零、统一 a0=1，区分 a 与反馈系数 -a | 带精确索引的 a/b 和状态递推 |
| 7. 数值与频域核对 | 同一快照创建连续参考、符号结果数值实例及独立库参考 | 伯德图与原始复响应数据、极点、误差 |
| 8. 逐拍执行核对 | 独立历史递推与状态递推，覆盖首拍/复位/重复 | 同时间轴误差；通过范围与未执行项 |
| 9. 参数化交付 | 外部系数生成函数与显式状态 step，附条件和依赖 | 可重新换参执行的脚本、差分方程及证据 |

## 公共子表达式不是新调参项

例如一般二阶系统可能定义 `r=omega*Ts`、`d=1+c1*r+c2*r^2`。
这些量由物理参数派生，不可与 omega/Ts 分别独立修改。先检查代换前后恒等，再由同一快照生成所有量。`subs` 后检查 `symvar`；不能假设代入原参数就会自动替换已独立创建的 r/d 符号。

若表达式同时包含 z 正幂和负幂，先统一变量再提系数。格式化的 LaTeX 或手抄公式不作为执行代码；应从结构化 a/b 导出文本，再由同一 a/b 执行与重建。

## 来源一致性与变体识别

同一个缩写、通道标签或同一谐振频率不能证明系统相同。对公式版本的核对至少关注分子分母、增益符号、DC 行为、高频极限、直接馈通与相位基准。两条表达式只在一个频率相同不等于全系统等价。

符号推导和库调用的比较必须共享同一快照。不同采样周期或物理参数的响应可用于灵敏度分析，但不能据此计算“推导误差”。参数扫描须保留每条曲线的参数集，不能用图标题代替。

## 用户示例的参考边界

读取的流程参考：`sogi2_formula_derivation_asv.mlx`、`sogi2_zdomain_fast.mlx`、`sogi1_lpv.mlx`、`sogi2_lpv.mlx`、`sogi3_lpv.mlx` 及 `Orthogonal_Generator.m`，来自用户指定的 `sogi2` 文件夹。示例仅作为资料阅读，未执行、未修改，也不作为技能运行时依赖。

示例展示了符号 TF → 双线性代换 → collect/numden → 公共量代换 → 数值 TF/c2d → Bode → filter/历史量递推的流程。通用技能保留该过程并补上方法选择、SS 路径、同快照验证、回代证明、复位和量化的独立验收。

阅读时发现需在通用流程防止的差异：

- 示例某 Q 通道写为 `-k*s^2/(s^2+k*wn*s+wn^2)`，另一个函数的系数对应 `k*wn^2/(s^2+k*wn*s+wn^2)`。技能不替用户认定哪个变体正确，也不会自动用标准名称替换公式。
- 示例不同片段采用不同 wn/Ts；只可作为不同配置，不是独立离散实现一致性的证据。
- `sin(f*t)` 中 f 是 rad/s；如果 f 表示 Hz，需使用 2*pi。频率单位与图题须从合同统一生成。
- 示例递推中的正反馈乘数采用 `-a1/-a2` 命名约定，通用输出统一为分母 a 系数并明确前置负号，避免照抄变量名称造成符号翻转。
- 示例 persistent 历史量与逐拍重算系数不是通用复用接口；技能采用显式实例状态及外部参数/系数输入。

这些规则是通用正确性约束，技能自测使用一阶系统、不同二阶系统、MIMO、静态增益与积分器验证，而非只套用该示例。
