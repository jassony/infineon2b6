# 验证与交付合同

本技能默认矩阵范围：符号验证用 theta 矩阵恒等式或 ZOH 指数的状态转移 ODE/初值残差，数值验证用矩阵输出与独立库/方法参考。下文 TF、q/a/b 和 I/O 递推交叉检查只在明确请求通道展开时适用，未请求项记录为 NOT_RUN 并排除出该范围必需门禁。

## 执行前

记录物理参数符号/含义/单位/范围/来源、Ts、方法、预畸变频率、生成依赖、系数类型、频带、时长与容差。`dv_realize` 只检查通用数值条件；调用者必须执行领域参数校验，例如 SOGI 的 k>0、f0 在允许频带。conditions 字符串不是已执行的校验。

设定两类独立准则：

1. 实现等价：`abs(test-ref)<=absTol+relTol*abs(ref)`，对每拍、每通道执行；double 和 single 分别设定。记录最大误差、最差索引及容差比，而非只看图。
2. 连续近似：根据任务设定频带内幅值/相位或复响应误差、时间响应指标。未给阈值时可以先报告观测并比较方法，验收项必须标 NOT_RUN，不能默认为 PASS。

频率输入用 Hz，调用 `freqresp` 时转为 rad/s，离散多项式用 `q=exp(-1j*2*pi*f*Ts)`。网格全部严格小于 Nyquist。包含关注频率和谐振附近加密点；不能只给默认 bode 图。

## 独立程度与检查内容

| 层次 | 检查 | 证据 |
| --- | --- | --- |
| 源方程 | 若有独立 TF/SS，比较；仅一份来源则核对推导 | 来源映射，不虚构第二份独立来源 |
| 符号 | theta 矩阵恒等式或 ZOH 转移 ODE/初值；可选 Gd/sMap/q 核对 | 化简残差和实际证明状态 |
| 数值系数 | Ts>0，有限值，M/归一化非奇异，完整 Ad 极点 | 参数快照与极点表 |
| 离散频响 | SS 频响，FE/BE 对连续矩阵的 sMap 求值，ZOH/Tustin 对 c2d；q 递推可选 | 逐频点复数误差 |
| 时间实现 | 显式状态步骤 vs 库/方法参考；通道历史递推可选 | 原始 t/u/reset/y 与逐拍误差 |
| 连续近似 | Gc(jw) 与 Gd(exp(jwTs)) 的同频率对比 | 伯德幅相叠图、幅相误差及原始复响应 |

对相位用 `angle(Hd*conj(Hc))` 或复数比值取主值误差；绘图各自 unwrap 只用于展示。参考或测试幅值低于明确 magnitudeFloor 时，相位误差记未定义，保存有效掩码。dB 差在零点也不定义；不要以裁剪后的数值作为验收数据。

ZOH 时域“精确”比较需要相同零阶保持输入。将光滑连续正弦与 ZOH 离散滤波器比较属于近似质量测试，不能要求逐拍零误差。连续单位面积冲激与离散单位样本冲激幅值不同，必须区分。

## 用例与状态时序

至少选择适合该系统的零输入、阶跃、单位样本、正弦、固定种子随机输入；覆盖非零首拍输入、运行中多拍复位、释放、末拍复位和重复运行。MIMO 用不同通道激励防止通道交换被掩盖。

所有参考使用相同 t，从 k=0 开始。当拍先输出，再保存下一状态；没有任何为了“对齐”而删除首拍、平移数组或重标时间的步骤。复位拍状态、输出及递推历史清零，忽略该拍输入。c2d 参考可以按复位分割成独立的零初态片段，保留原数组位置。

零辅助初值与物理初值分别测试；需要非零物理初值时使用记录的状态映射，并通过物理更新/输出公式独立核对首拍。当前 `dv_verify` helper 固定零辅助初值；不能将其结果推广至非零初态。

系统极点在单位圆外：标 UNSTABLE，跳过长时间回放并写明原因。单位圆边界（积分器等）不叫渐近稳定；若任务允许，单独设置有限时域指标和回放。helper 将两者都排除出默认渐近稳定回放，但报告中应区分。

如计划 single 实现，在转换到 single 后重新检查极点并逐拍对比 double，不能用 double 结果代替。两个参数不同且独立复位的同时实例才证明实例隔离；当前 helper 不自动证明硬件、调度或 Simulink 复用。

## 报告最小内容

- 来源与约束、方法理由、符号推导/化简状态及状态映射。
- 完整外部参数快照；基础参数与派生系数分开，明确冻结及重新离散化时机。
- a/b 索引、当前输入直通项、状态与历史初值、计算次序和复位行为。
- 连续/离散伯德幅相对比，原始频响 CSV、幅相误差、极点及时间误差数据。
- 每项 PASS/FAIL/NOT_RUN、最差误差、跳过理由和软件版本。
- 目标频带精度结论与实现等价结论分别呈现。技能自测不等于用户算法验收，MATLAB 验证不等于 Simulink 验证。

交付可再执行的脚本和数据；图片要能追溯参数和频率单位。单靠截图、已有历史报告、代码静态检查或未执行脚本都不能宣称验证完成。
