# MATLAB 状态空间离散化

从连续 `xdot=A*x+B*u; y=C*x+D*u` 得到参数化 Ad/Bd/Cd/Dd、明确状态意义和时序的可执行递推，以及频域/时域验证证据。面向一般线性对象、控制器和观测器子系统，不固定算法、通道数或参数名称。

主输入若是 TF 且目标是 I/O 历史递推，使用 `matlab-discretize-transfer-function`。本技能以状态方程为交付主线；只有低阶、交叉核对或用户需要时才展开通道传函和 I/O 多项式，不强制大矩阵求逆/行列式展开。

## 1. 状态与参数合同

- 记录来源/版本、A/B/C/D、每个状态/输入/输出的含义和单位、物理参数范围、Ts、保持、初态/复位、关注频带、验收指标和实现类型。检查维度、直接馈通及耦合关系。
- 从原方程提取状态矩阵时证明映射；只有另一份独立 TF 来源才算交叉源验证。符号名或通道名不能代替方程身份核对。
- 读取 [通用资料流程](references/source-workflow.md) 和 [方法与状态映射](references/methods.md)。示例用于参考工作顺序，不成为运行时输入或固定默认配置。
- 检查 MATLAB、Symbolic Math Toolbox、Control System Toolbox。缺工具时区分可做的数值工作与未执行的解析推导，不自动启动 Simulink。

## 2. 可选择的方法与统一实现

根据保持、频域精度、计算量和稳定性选择单方法或列表；不要求所有任务比较全部方法。

- **FE**：显式欧拉，旧物理状态产生当拍输出，输入参与下一状态；检查 Ts 相关稳定性。
- **BE**：解析消除隐式方程，保留当拍输入直通；不能简单把 `Ad=(I-Ts*A)^-1` 与旧 C/D 随意组合。
- **Tustin／预畸变 Tustin**：对完整系统变换，输出方程随状态变换一起推导；注明辅助状态与物理状态的关系。
- **ZOH**：增广 `expm(Ts*[A B;0 0])` 提取 Ad/Bd，C/D 保持；不依赖 A 可逆，适用于积分器等奇异 A。

统一输出 `xi[n+1]=Ad*xi[n]+Bd*u[n]`、`y[n]=Cd*xi[n]+Dd*u[n]`。FE/BE/Tustin 的 theta 推导、预畸变有效积分步长及初态映射见方法参考；数值系数用线性求解，不在逐拍函数求逆。

保留物理参数和 Ts 符号，使用有限量化简并记录所有奇异条件/公共量依赖。大系统符号表达式膨胀时保留严格矩阵形式并验证数值实例，不把未展开的解析式标为已化简完成。

## 3. 状态、初态与复位

- 说明 xi 是物理状态、上一拍状态还是辅助坐标。BE/Tustin 的零离散状态不自动等于非零 u0 下的零物理状态；如规定物理 x0，使用推导得到的输入相关映射。
- 先根据旧状态和当前输入输出，再计算/提交下一状态。复位优先：本实例当拍输出、状态为零（包括屏蔽 Dd*u），该拍输入不进入状态历史；释放行为明确。
- 参数由外部完整快照提供，离线校验/生成并冻结；逐拍函数显式接收状态、u、reset、参数/系数。无 base workspace、SLDD 查询或跨实例共享可变全局值。Ts 值是设计周期，不能替代调度配置。
- 用 `matlabFunction` 明确输入参数顺序，生成外部系数函数。single 或定点实现另做转换后极点、条件和误差验证；double 参考不证明目标类型通过。

## 4. 独立验证与交付

读 [验证合同](references/verification.md)，先设容差、频带、幅值下限及用例，再执行。

- 检查完整 Ad 的极点，包括 TF 约消看不到的内部状态；积分器边界稳定与发散分别报告。不稳定候选不能靠限幅或只看 I/O 传函隐藏。
- 用独立 c2d 参考或方法映射比较输出/频响，不直接比較不同坐标下的内部状态。相同源/参数快照/Ts/输入保持/初态/复位必须贯穿所有路径。
- 对低阶系统可用独立通道 I/O 递推交叉验证；对于大状态系统可省去多项式展开，使用矩阵公式残差、独立库输出及适合的物理解析/数值参考，并报告实际覆盖。
- 伯德图按各 I/O 通道叠加连续/离散幅相，提供复响应与误差数据。网格严格低于 Nyquist，统一 Hz/rad/s；零增益通道的相位不定义。
- 显式状态 step 与独立参考逐拍比较，不平移时间轴；覆盖合适激励、首拍非零输入、复位/释放、重复运行和所需非零物理初态。MIMO 不同通道分别激励；需要复用时验证两个同时实例的独立状态/复位/参数。
- 实现一致性、连续近似质量、目标类型和模型/代码验收分别报告 PASS/FAIL/NOT_RUN。

主交付为参数合同、连续→离散矩阵推导、Ad/Bd/Cd/Dd 符号及数值矩阵、状态/初态映射、可直接执行的状态递推 `.m`、伯德图/频域数据、极点/时域误差及报告。I/O 差分方程只在有益或用户要求时作为附加结果。

## 可执行起点与范围

读 [脚本接口](references/scripts.md)，首选 `scripts/dv_from_ss.m`。本技能自带独立完整的 helper，不要求安装 TF 技能。默认只做矩阵推导和验证，可显式请求通道多项式交叉核对。当前符号 ZOH helper 会求增广指数的解析展开，复杂大矩阵应改用保留指数表达式和数值 expm 的专门脚本，并如实记录未展开状态。

对 `E*xdot=A*x+B*u`、奇异描述系统、时变/非线性状态、纯延时或微分输入，先明确专门方法；不静默消除 E、线性化、丢弃延时或假装 c2d 普遍适用。参数化线性矩阵表示“每次运行冻结参数”，不等于已经验证 LPV 在线改参。

技能自测只证明工具本身覆盖范围；不自动修改既有模型、FOC 或 A2L。
