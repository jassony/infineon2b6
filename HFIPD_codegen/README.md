# HFIPD 初始位置辨识

已接在本项目预定位之前；默认禁用。此模块通过电压注入及电流响应辨识
静止转子的**电角度**，不作为运行观测器，也不接管 KRE 的速度反馈。

## 使用与启动顺序

- `Cal_HFIPD_Enable_u8=0`：整段辨识旁路，不写入初始角度。
- `Cal_HFIPD_Enable_u8=1`：下一次启动先辨识，成功后将电角度一次性写入
  I/f 角度积分器及预定位坐标系，再开始原有预定位计时。
- `Cal_FocStartupMode_u8=0`：辨识 → 预定位 → 原 KRE/Flux 闭环交接。
  保留非零预定位时间、观测器预热和有效估计条件。
- `Cal_FocStartupMode_u8=1`：辨识 → 预定位 → I/f → 原闭环交接。
- 辨识失败：注入置零，不写角度，保留失败状态，继续原有预定位启动。
  不使用失败角度，也不隐式切换运行观测器。
- 停止/故障：结束本次辨识并清除有效结果；再次启动重新辨识。
  辨识期间的停止直接返回 standby，不进入速度减速阶段。

标定只在停止到运行的 2 kHz 边界捕获，运行中改值不影响当前辨识。
组写时先将 `Cal_HFIPD_Seq_u16` 写成奇数，写完参数后改成下一个偶数，
最后启动；奇数或捕获期间变化的组会拒绝。该协议需要标定端遵守。
开关在启动边界锁存，运行中写 0 不是急停，停止仍使用原控制命令。

有效角度读取条件为 `Meas_HFIPD_Valid_u8=1`。无效时
`Meas_HFIPD_Init_rad_f32=0` 只是清除值，不表示辨识到了零度；
`HFIPDInjection_consume` 返回 0 且不修改调用者的角度参数。
`Meas_HFIPD_Track_rad_f32` 是过程诊断，不可代替有效输出。

## 方程、时序与接口

来源及基线见 [INTEGRATION.md](INTEGRATION.md)。原仿真 S-Function 无 TLC，
本次采用手写 C 移植，不宣称生成了 ERT 或新增了可代码生成的 SLX。
独立 MATLAB reference → C 回放 → 接口/生产代码回放 → 两种所有权构建
已执行；原模型结构和 A2L 未修改。

固定 Ts=50 us、fh=1 kHz、N=20。更改调度必须重新离散化并验证；没有运行
中修改 Ts 或 fh 的入口。每个快环输入当前 alpha/beta 电流，输出本拍电压
指令；实际 PWM/采样延迟由 Delay 参数补偿，默认两拍是待台架确认的假设。
使用项目的 50 A/1000 V Q15 基准，仅在 MS 边界换算一次。

令 c=cos(theta)、s=sin(theta)，id=c*ia+s*ib，iq=-s*ia+c*ib。
滑动 DFT 为 X[k]=exp(j*2*pi/N)*(X[k-1]+iq[k]-iq[k-N])。
幅值 A=2*abs(X)/N，重建值 r=2*Re(X*exp(-j*2*pi/N))/N。
按论文图 5 的 -1/0/+1 符号计数器对
r*cos(2*pi*(k-delay)/N) 判号；err=sign*A。
thetaNext=wrap(theta-Ts*(Kp*err+integral))，
integralNext=integral+Ts*Ki*err。前 N 拍只填充窗口。
输出电压使用更新前的 theta，防止多引入一拍相位偏移。

两次跟踪分别从 Init 和 Init+pi/4 开始，中间先撤压静置、清除 DFT/PI
历史。将两次末值差折叠到 [0,pi/2]，超出 AxisHi 时拒绝。
之后沿第二次跟踪轴施加正、负脉冲；撤压后分别积分 max(id,0) 和
max(-id,0)。要求 abs(Spos-Sneg)>Contrast*(Spos+Sneg)，且面积和大于 0；
Spos>Sneg 时修正 pi。该规则继承原饱和假设，真实磁极响应需要实测。

核心状态均为实例局部：20 个 iq 历史、DFT 实虚部、PI 积分、当前/首次
磁轴、两面积极分、符号计数器、阶段计数和状态。reset/start 清零所有
历史并采用冻结 Init；第二次跟踪仅重置跟踪历史。有限参数范围保证
数值有界；NaN/Inf 电流、超流、单拍角度变化超过 pi、轴不一致、极性
不明确均拒绝，不通过夹角或替代数值伪造有效结果。
适配器为本项目唯一电机保存一个核心实例；独立核心可由调用者多实例化。

20 kHz 分支位于测量/重构之后、主观测器与电流 PI 之前，辨识期间直接
生成极坐标电压交给原调制器。HFI 输出许可被关闭；主观测器从随后的
零参考间隔/预定位开始正常预热。强制占空比或母线无法提供完整注入幅值
时拒绝辨识结果；不会改写外部强制占空比设置。
2 kHz 分支消费结果一次，保持辨识期间预定位剩余计数不变。
快/慢环维持相同抢占优先级 1；未移动前台任务或修改中断优先级。

## 标定表

全部为 `NO_OPT volatile`，位于原 `.xcp_cal_m4`；未生成 A2L。
以下省略共同前缀 `Cal_HFIPD_`，浮点均为 single，tick=50 us。

| 符号后缀 | 默认 | 有效范围 / 含义 |
|---|---:|---|
| Enable_u8 | 0 | 非零在下次启动启用 |
| Seq_u16 | 0 | 偶数为完整组，奇数为编辑中 |
| Hf_V_f32 | 20 | (0,100] V，正弦峰值 |
| Pulse_V_f32 | 10 | (0,100] V，极性脉冲幅值 |
| Kp_radpsperA_f32 | 2000 | (0,100000] rad/(s*A) |
| Ki_radps2perA_f32 | 0 | [0,1000000] rad/(s²*A) |
| Init_rad_f32 | 0 | [-pi,pi] 电角度初始猜测 |
| Delay_tick_f32 | 2 | [0,19]，采样/施压延迟补偿 |
| Contrast_PU_f32 | 0.01 | (0,1)，面积相对差阈值 |
| AxisHi_rad_f32 | 0.13962634 | (0,pi/4)，默认 8° |
| IsHi_A_f32 | 45 | (0,1000] A，电流矢量幅值上限 |
| Track_tick_u16 | 300 | [40,20000]，每次跟踪 15 ms |
| Settle_tick_u16 | 400 | [20,20000]，每次静置 20 ms |
| Pulse_tick_u16 | 800 | [1,20000]，每个脉冲 40 ms |
| Tail_tick_u16 | 800 | [1,20000]，每个撤压积分窗 40 ms |
| Gap_tick_u16 | 300 | [20,20000]，正负试验间隔 15 ms |

默认完整辨识 4900 拍=245 ms，比原单次跟踪版本多 35 ms。
发布角度/开始预定位还需等待下一次 2 kHz 边界；既有预定位时长不计入
245 ms。阶段计数有明确上限，没有无限等待的识别阶段。

`Meas_HFIPD_Stat_u8`：0 空闲，1 首次跟踪，10 跟踪间静置，9 第二次
跟踪，2 极性试验前静置，3 正脉冲，4 正下降沿积分，5 间隔，6 负脉冲，
7 负下降沿积分，8 成功，11 参数拒绝，12 非法/超限电流，13 磁轴拒绝，
14 极性拒绝，15 电压不可用。Act 表示阶段仍占用启动电压路径（包括
等待 2 kHz 消费的结束状态）；Valid 表示角度可用，两者含义不同。
其它测量包含 Init/Track 角、Pos/Neg 面积 [A*s]、Axis 差 [rad]、
Err/Hf 电流 [A]、Out 电压 [V]、Time 快环计数。

## 验证与复跑

1. MATLAB：添加 `HFIPD_codegen/tests` 后执行 `run_hfipd_replay`。
2. PowerShell：执行 `tests/run_hfipd_tests.ps1`（IAR 核心/适配器回放）。
3. 执行 `tests/run_hfipd_startup_tests.ps1`（提取实际启动/快环/停止函数）。
4. 执行 `MS/tests/run_foc_stop_current_tests.ps1`（原禁用路径停止回归）。
5. 执行 `tests/run_hfipd_builds.ps1`（生产及独立 Flux 诊断构建）。

脚本输出、逐拍输入/参考/C 数据及固件保存在 Build/HFIPD_Tests，测试
数据使用假设锁转子电气模型，不是伪造的实测电流。门限在运行前定义：
接受角度误差 <4°，C/reference 角差 <0.1°，电压差 <1e-4 V，面积差
<1e-4 A*s，阶段/有效标志完全一致。结果见 [reports/VALIDATION.md](reports/VALIDATION.md)。

**尚未完成实机标定/验收。** 目标名义 R/L 比论文模型凸极性更弱；默认
参数的三个目标敏感性工况中，120°/240° 被拒绝，30° 被接受。这说明
论文默认值不能直接当成本电机的已验证标定。两次磁轴一致也不是对任意
噪声、负载、饱和曲线或运动转子的准确度证明。完整台架门禁保持 NOT_RUN。
